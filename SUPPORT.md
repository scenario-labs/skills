# Support

Scenario Agent Skills are maintained by Scenario. This page says where to look and whom to ask.

## Using the skills

- Start with the [README](README.md) for what each skill does and how to install it, and
  [INSTALL.md](INSTALL.md) for the install commands by role and goal.
- The `scenario` skill connects an agent to the [Scenario MCP server](https://mcp.scenario.com). Its
  [documentation](https://mcp.scenario.com/docs) and
  [tool reference](https://mcp.scenario.com/docs/tools) cover every tool and parameter.
- For models, credits, and account settings, see the
  [Scenario Knowledge Base](https://help.scenario.com). The
  [API documentation](https://docs.scenario.com) covers the platform API.
- The expert tools drive applications installed on your machine. Each family folder's README says
  how it was built and how far it was verified.
- For what changed, read the [changelog](CHANGELOG.md) and the
  [releases](https://github.com/scenario-labs/skills/releases).

## Bugs, change requests, and questions

Use the [issue chooser](https://github.com/scenario-labs/skills/issues/new/choose). Search the
[existing issues](https://github.com/scenario-labs/skills/issues) first. For a question, open a
blank issue with a title starting with "Question:".

Before filing a bug, collect:

- The skill name, and the agent and operating system you ran it with.
- For an expert tool, the application and its version.
- The exact tool calls with their arguments, what you expected, and what happened.
- Trace ids from `diagnostics_run`, job ids, model ids, and the UTC time of the failing call.

Issues are public and permanent. Never include an API key, a token, a signed asset URL, or a team or
project id you do not want published.

## Account, billing, credits, and security

Keep these out of public issues. Write to [support@scenario.com](mailto:support@scenario.com) or use
in-app support at [app.scenario.com](https://app.scenario.com). Report vulnerabilities as
[SECURITY.md](SECURITY.md) describes.

## What to expect

Issues here are handled on a best-effort basis, with no response-time commitment. Support for your
Scenario account or subscription goes through the channels above.
