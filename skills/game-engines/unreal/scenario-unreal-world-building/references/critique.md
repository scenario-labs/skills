# Critique rubric: judging a world like the experts

Use at every stage gate: numbers first (toolkit output), then the captures you opened. Each line: what to look at, pass, fail and what to do. Sources in brackets; [added] marks this skill's own threshold. A capture that `ue_review.image_checks` flags as all white or all black is not evidence; retake it.

## 1. Plan and tiers

| Look at               | Pass                                                                           | Fail and fix                                                                                          |
| --------------------- | ------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| World spec            | `check_world_spec` ok; every info finding answered or written as an assumption | missing speed, frame budget or platform: ask the lead, write the default                              |
| Manual vs procedural  | village layout, river course, roads, hero areas hand-placed and named          | a procedural road or village generator for a small map: drop it (Oztalay [00:32:26]; Dark [00:11:13]) |
| Placement tiers       | hero hand, trees and rocks baked, grass runtime (`placement_tier`)             | trees or gameplay items at runtime: bake (icIFFlOyob4 [00:04:23]; Sensei [00:54:16]; Dark [00:07:56]) |
| Experimental features | named, with the reason the project accepts them                                | Mesh Terrain, Nanite Foliage, PVE, FastGeo on a shipping plan without sign-off                        |
