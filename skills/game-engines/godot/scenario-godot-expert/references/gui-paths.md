# scenario-godot-expert: GUI paths

The same tasks as `procedures.md`, done by hand in the Godot 4.7 editor (for a computer-use agent or a human). None of these was clicked through here: the GUI editor takes focus on this Mac, so the headless equivalents in the right column are what ran. On macOS, Cmd replaces Ctrl in editor shortcuts. Menu names follow the 4.7 editor; [verify] marks paths not confirmed in the saved docs or videos.

| Task                                      | GUI path                                                                                                                                                                                                                                                                         | Headless equivalent (ran)                                                                   |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Install export templates                  | Editor > Manage Export Templates > Download and Install, or Install from File (the `.tpz`) [verify]; 4.7 adds per-platform downloads (deltas section 18)                                                                                                                         | `gd_env.install_templates()`                                                                |
| Create a project with 4.7 defaults        | Project Manager > Create: pick the renderer; Jolt, `canvas_items`/`expand` and the D3D12 Windows driver are set by the editor (deltas section 15)                                                                                                                                | `gd_env.new_project(...)`                                                                   |
| Project settings                          | Project > Project Settings; turn on Advanced Settings to see every key (Godot docs, Static typing page); the key path is the tree path, for example Physics > 3D > Physics Engine, Display > Window > Stretch > Mode, Rendering > Textures > VRAM Compression > Import ETC2 ASTC | `gd_env.set_project_setting(P, key, literal)`                                               |
| Enable a plugin (GUT, hybridindie addon)  | Project > Project Settings > Plugins tab > Enable (Godot docs, Making plugins; hybridindie README)                                                                                                                                                                               | `gd_env.install_gut(P)` writes `[editor_plugins]`                                           |
| Run an EditorScript                       | Script editor File > Run (Ctrl+Shift+X); FileSystem dock right-click > Run; command palette Ctrl+Shift+P, "Editor Scripts" section (4.5+) (Firebelley Games, VyTys5oCdN8; HeartBeast, MX2I3376ubE)                                                                               | `run_script(P, job, editor=True)`                                                           |
| Upgrade old scene files                   | Project > Tools > Upgrade Project Files (deltas section 15, 4.6)                                                                                                                                                                                                                 | open and save through a `-e` job                                                            |
| Run the game / current scene              | Run Project (F5; Cmd+B on macOS [verify]); Run Current Scene (F6; Cmd+R [verify])                                                                                                                                                                                                | `run_script` with a job, `capture_scene`                                                    |
| See collision shapes and navigation       | Debug > Visible Collision Shapes, Visible Navigation (Bacon and Games, P7AQLUU3xKk [00:15:06])                                                                                                                                                                                   | `extra_args=["--debug-collisions"]` or `["--debug-navigation"]` on a windowed capture       |
| Inspect the running game                  | Scene dock > Remote while the game runs; Editor Settings "Always Switch to Remote Scene Tree" (Bacon and Games [00:03:16])                                                                                                                                                       | a job that reads the values; an MCP into the running game                                   |
| Profiler and monitors                     | Debugger bottom panel > Profiler, Visual Profiler, Monitors (Godot docs, The Profiler)                                                                                                                                                                                           | `profile_scene(...)` (CSV plus `budget_check`)                                              |
| Read errors                               | Debugger > Errors tab and the Output panel (stale after edits: Fennara, 2vSYP7GyA5U [00:02:51])                                                                                                                                                                                  | `gd_run` result dict, `check_all`                                                           |
| Export presets and builds                 | Project > Export: Add preset, set options, Export Project or Export PCK/ZIP [verify]                                                                                                                                                                                             | `ensure_preset`, `export`, `verify_pack`                                                    |
| Run GUT tests                             | GUT bottom panel > Run All                                                                                                                                                                                                                                                       | `run_tests(P, "gut")`                                                                       |
| GdUnit4 test stub                         | right-click a function > Create Test (Mike Schulze, x6GdTgIAFiU [00:10:38])                                                                                                                                                                                                      | write `test_*.gd` by hand (gdUnit4 not installed here)                                      |
| Tool button in the Inspector              | click the `@export_tool_button` (Queble, nW7YtSSJzbQ)                                                                                                                                                                                                                            | call the Callable from a job                                                                |
| Editor broken by a plugin                 | relaunch with recovery mode (`--recovery-mode`, Godot docs, Command line tutorial)                                                                                                                                                                                               | n/a                                                                                         |
| Open the user's project for MCP work      | open the project from the Project Manager, enable the MCP addon, keep the editor open                                                                                                                                                                                            | `gd_live.open_editor(P)` only on request; `gd_live.write_mcp_config(P, "hybridindie")`      |
| Visual editors with no scripted authoring | VisualShader editor, AnimationTree panel, TileSet editor, Theme editor, particle inspector                                                                                                                                                                                       | `.gdshader` text, resources built in code or written as `.tres`, owned by the domain skills |
