# scenario-godot-ui: GUI paths (Godot 4.7.2 editor)

The same steps for a computer-use agent or a human. The code substitute is listed first; it is what the agent runs headless. Not run through the GUI in this session: these paths come from the sources and the 4.7.2 property names, verified to exist through ClassDB and ProjectSettings.

| Task                                   | Code substitute                                                                                         | Editor path                                                                                                                                                                                                    |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Stretch mode, aspect and base size     | `gd_env.set_project_setting(P, "display/window/stretch/mode", '"canvas_items"')` and so on              | Project > Project Settings > Display > Window > Size (Viewport Width and Height), Stretch (Mode, Aspect, Scale, Scale Mode). Turn on Advanced Settings for Scale Mode.                                         |
| Handheld orientation                   | `display/window/handheld/orientation=6`                                                                 | Project Settings > Display > Window > Handheld > Orientation: Sensor                                                                                                                                           |
| Project theme                          | `gui/theme/custom`                                                                                      | Project Settings > GUI > Theme > Custom                                                                                                                                                                        |
| MSDF default font, Default Theme Scale | `gui/theme/default_font_multichannel_signed_distance_field`, `gui/theme/default_theme_scale`            | Project Settings > GUI > Theme (Advanced)                                                                                                                                                                      |
| Build a Theme                          | `ui_theme.gd` `build()`, then `ResourceSaver.save(theme, "res://ui/theme/game_theme.tres")`             | FileSystem > right click > New Resource > Theme. Double-click it to open the Theme editor (bottom panel). Use "+" (Add Type) to add a type; for a variation, add the type and set Base Type in the wrench tab. |
| StyleBox                               | `StyleBoxFlat.new()` in code                                                                            | Inspector > Theme Overrides > Styles > New StyleBoxFlat. Make Unique before reuse.                                                                                                                             |
| Type variation on a node               | `node.theme_type_variation = &"HudValue"`                                                               | Inspector > Theme > Type Variation (type the name if it is not in the dropdown)                                                                                                                                |
| Anchors and presets                    | `set_anchors_and_offsets_preset(Control.PRESET_BOTTOM_RIGHT)`, `grow_horizontal = GROW_DIRECTION_BEGIN` | 2D toolbar > Anchor preset menu (green icon), Inspector > Layout > Anchors Preset, Layout > Grow Direction                                                                                                     |
| Size flags                             | `size_flags_horizontal = SIZE_EXPAND_FILL`                                                              | Inspector > Layout > Container Sizing > Horizontal: Fill and Expand                                                                                                                                            |
| Mouse filter                           | `mouse_filter = MOUSE_FILTER_IGNORE`                                                                    | Inspector > Mouse > Filter: Ignore                                                                                                                                                                             |
| Focus neighbors and mode               | `focus_neighbor_bottom = NodePath(...)`, `focus_mode`                                                   | Inspector > Focus > Neighbor Bottom (node picker), Mode                                                                                                                                                        |
| Accessibility                          | `accessibility_name`, `accessibility_live`, `focus_mode = FOCUS_ACCESSIBILITY`                          | Inspector > Accessibility > Name, Description, Live                                                                                                                                                            |
| Translations                           | CSV in `res://ui/i18n/`, `--import`, `gd_ui.register_translations(P)`                                   | Project Settings > Localization > Translations > Add, pick the `.translation` files                                                                                                                            |
| Locale test                            | `godot --path P --language fr`                                                                          | Project Settings > Internationalization > Locale > Test. Clear it before committing.                                                                                                                           |
| Pseudolocalization                     | `TranslationServer.pseudolocalization_enabled = true`, then `reload_pseudolocalization()`               | Project Settings > Internationalization > Pseudolocalization (Advanced)                                                                                                                                        |
| Input map for pads                     | `InputMap.action_add_event("ui_accept", pad_event)` or project setting `input/ui_accept`                | Project Settings > Input Map > Show Built-in Actions > ui_accept > "+"                                                                                                                                         |
| Accessibility support                  | `accessibility/general/accessibility_support`                                                           | Project Settings > Accessibility > General (Advanced)                                                                                                                                                          |
| Text Server Data on export             | export preset option                                                                                    | Project > Export > preset > Resources or Features: Include Text Server Data (see scenario-godot-performance-export)                                                                                            |
| Custom RichTextEffect                  | `label.install_effect(effect)`                                                                          | Inspector > Markup > Custom Effects > add                                                                                                                                                                      |
| `offset_transform`                     | `offset_transform_enabled = true`, tween `offset_transform_scale`                                       | Inspector > Transform (Offset Transform group, 4.7)                                                                                                                                                            |
| Preview at device sizes                | `gd_ui.layout_matrix`, `gd_ui.capture_matrix`                                                           | Editor Settings > Run > Window Placement, or Project Settings > Display > Window > Size > Window Width Override and Height Override for test runs. Clear the overrides after.                                  |
