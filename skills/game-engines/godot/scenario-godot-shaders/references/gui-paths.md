# scenario-godot-shaders GUI paths (Godot 4.7 editor)

These are for a computer-use agent or a human. Each line names the procedure it mirrors. Menu names follow the 4.7 editor. They were not driven by a GUI agent here: the editor was not opened, because the procedures run without it.

| Task                         | GUI path                                                                                                                                                                                                                  | Scripted equivalent                                                     |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| New text shader              | FileSystem dock, right click, Create New, Resource, Shader (or Inspector, Material, New ShaderMaterial, Shader, New Shader); pick the Type (Spatial, CanvasItem, Particles, Sky, Fog) and Mode Text                       | write `res://shaders/x.gdshader` (P1)                                   |
| Shader include               | Create New, Resource, ShaderInclude (`.gdshaderinc`)                                                                                                                                                                      | write the file; `#include "x.gdshaderinc"` (P4)                         |
| Shader errors                | bottom panel Shader Editor, the error line under the code; Output panel                                                                                                                                                   | `compile_matrix`, `draw_check` (P2, P3)                                 |
| VisualShader graph           | Create New, Resource, VisualShader; Shader Editor, right click on the graph, Add Node; drag from port to port; the script icon at the top right shows the generated code                                                  | `examples/build_visual_shader.gd`, `shader_tools.gd:visual_shader` (P9) |
| Convert VisualShader to text | Inspector on the ShaderMaterial, Shader, dropdown, Convert to Shader (one way)                                                                                                                                            | `VisualShader.get_code()` saved to `.gdshader` (P9)                     |
| Set a material uniform       | Inspector, Material, Shader Parameters                                                                                                                                                                                    | `ShaderMaterial.set_shader_parameter`                                   |
| Set an instance uniform      | select the MeshInstance3D, Inspector, GeometryInstance3D, Instance Shader Parameters                                                                                                                                      | `set_instance_shader_parameter` (P7)                                    |
| Animate a uniform            | AnimationPlayer, Add Track, Property Track, pick the node, `instance_shader_parameters/dissolve_amount` (or the material's `shader_parameter/x`)                                                                          | `Animation.track_set_path` (P8)                                         |
| Register a global uniform    | Project, Project Settings, Shader Globals tab, name, type, value, Add                                                                                                                                                     | `gd_shaders.register_global` (P11)                                      |
| Glow for emissive edges      | WorldEnvironment, Environment, Glow, Enabled                                                                                                                                                                              | `Environment.glow_enabled = true` (P7)                                  |
| Stencil presets              | Inspector on a StandardMaterial3D, Stencil, Mode (Outline, X-Ray or Custom; Custom shows Flags Read, Write, Write Depth Fail, Compare, Reference), Color, Outline Thickness (seen in LowQualityCoding frames at 00:07:38) | `stencil_mode`, `stencil_color`, `stencil_outline_thickness` (P10)      |
| Shader stencil               | in the shader: `stencil_mode write, compare_always, 1;`; Material, Render Priority                                                                                                                                        | text, `render_priority` (P10)                                           |
| Full-screen quad             | Camera3D, add child MeshInstance3D, Mesh QuadMesh, Size 2 x 2, Flip Faces on; GeometryInstance3D, Extra Cull Margin 16384                                                                                                 | `examples/build_fx_scenes.gd` (P15)                                     |
| Sky shader                   | WorldEnvironment, Environment, Background Sky, Sky, Sky Material, New ShaderMaterial                                                                                                                                      | `Sky.sky_material` (P16)                                                |
| Noise textures               | Inspector, texture slot, New NoiseTexture2D or 3D, Noise, New FastNoiseLite, Seamless on                                                                                                                                  | `ShaderTools.noise_texture_2d/3d` (P4, P7)                              |
| Compute GLSL                 | double click a `.glsl` with `#[compute]`; Inspector shows the compile status                                                                                                                                              | `RDShaderSource` and `shader_compile_spirv_from_source` (P12)           |
| Shader baker                 | Project, Export, select the preset, Options, Shader Baker, Enabled                                                                                                                                                        | the preset option `shader_baker/enabled=true` (P14)                     |
| Renderer switch              | top right renderer dropdown (Forward+, Mobile, Compatibility); restarts the editor                                                                                                                                        | `--rendering-method` per run (P2, P4)                                   |
