# scenario-godot-animation: GUI paths

The same tasks as `procedures.md`, done by hand in the Godot 4.7 editor, for a computer-use agent or a human. None was clicked through here: the GUI editor takes focus on this Mac, so every headless equivalent was run instead (see the procedure). Paths come from the Godot docs and the videos cited; [verify] marks menu wording not seen on screen.

| Task                                               | GUI path                                                                                                                                                                                                                                                    | Headless equivalent (ran)                                                                                                |
| -------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Create a clip and keys                             | Select AnimationPlayer > Animation panel (bottom) > Animation > New; key icon next to inspector properties, or Insert Key in the track (doc-animation-player)                                                                                               | `Animation.new()`, `add_track`, `track_insert_key`; `anim_rig.gd:bake_clip`, `anim_cutscene.gd:build` (P1, P13)          |
| RESET track                                        | Animation > New named `RESET`, or accept "Create RESET Track(s)" when keying; Edit > Apply Reset; AnimationPlayer inspector Reset On Save (ghYilg9cq-I 00:01:01)                                                                                            | add an `RESET` clip with every animated path; audit flags gaps (P2)                                                      |
| Method, animation and audio tracks                 | Animation panel > Add Track > Call Method Track / Animation Playback Track / Audio Playback Track (doc-animation-tracks)                                                                                                                                    | `TYPE_METHOD`, `TYPE_ANIMATION` tracks in `anim_cutscene.gd` (P13); audio not run                                        |
| Markers and sections                               | Animation panel timeline right-click > Insert Marker [verify]; play a section from the marker context menu [verify]                                                                                                                                         | `Animation.add_marker`, `play_section_with_markers` (P13)                                                                |
| Loop mode of an imported clip                      | Double-click the .glb > Advanced Import Settings > Animations > clip > Loop Mode (fq0hR2tIsRk 00:09:59)                                                                                                                                                     | `_subresources.animations[name]["settings/loop_mode"]` (P3)                                                              |
| Import as Animation Library                        | Select the file > Import dock > Import As: Animation Library > Reimport (doc-import-3d-scenes-animation)                                                                                                                                                    | `set_import_options(..., importer="animation_library")` (P3, P5)                                                         |
| Import rest as RESET, FPS, remove immutable tracks | Import dock > Animation section (doc-import-3d-scenes-animation)                                                                                                                                                                                            | `[params]` `animation/*` keys (P3)                                                                                       |
| BoneMap retarget                                   | Advanced Import Settings > select Skeleton3D > Retarget > Bone Map > New BoneMap > Profile: SkeletonProfileHumanoid; fix red bones by hand; Reimport (nb6uSeEZFCI 00:02:22)                                                                                 | `anim_import.gd:make_bonemap` then `retarget/bone_map` (P4)                                                              |
| Skip the second character's clips                  | Advanced Import Settings > AnimationPlayer node > Skip Import (nb6uSeEZFCI 00:04:36)                                                                                                                                                                        | `_subresources.nodes["PATH:AnimationPlayer"]["import/skip_import"]` [verify]; P5 used a clip-free character file instead |
| Load a shared library                              | AnimationPlayer > Animation > Manage Animations > Load Library; Make Unique (nb6uSeEZFCI 00:04:36 to 00:05:08)                                                                                                                                              | `anim_setup.gd:share_library` (P5)                                                                                       |
| Build an AnimationTree                             | Add AnimationTree, Anim Player = the player; Tree Root = New AnimationNodeBlendTree; bottom AnimationTree panel: right-click Add Node; pencil icon opens a StateMachine or BlendSpace; drag between nodes for transitions (doc-animation-tree; E6ajmQhOeo4) | `anim_tree.gd:make_tree_root` (P6)                                                                                       |
| Transition settings                                | Click a transition arrow > Inspector: Xfade Time, Switch Mode, Advance Mode (set Auto), Condition or Expression; AnimationTree inspector Advance Expression Base Node (iElHZhOxGYA 00:04:31)                                                                | `AnimationNodeStateMachineTransition` properties (P6)                                                                    |
| OneShot filter                                     | Select the OneShot node > Edit Filters > tick bones (E6ajmQhOeo4 00:03:15)                                                                                                                                                                                  | `filter_enabled`, `set_filter_path` (P7)                                                                                 |
| Root motion                                        | AnimationTree (or AnimationPlayer) inspector > Root Motion > Track: Assign > pick the Root bone; add a RootMotionView to see it (fq0hR2tIsRk 00:11:51 to 00:13:33)                                                                                          | `root_motion_track` (P8)                                                                                                 |
| IK nodes                                           | Skeleton3D > Add Child Node > TwoBoneIK3D (or FABRIK3D, CCDIK3D); Settings > add element: Root, Middle, End bone, Target Node, Pole Node; Marker3D targets (MbaPDWfbNLo 00:02:36 to 00:03:40)                                                               | `anim_ik.gd:add_leg_ik` (P10)                                                                                            |
| Custom modifier                                    | New script `extends SkeletonModifier3D` on a Skeleton3D child; order children so it runs before the IK                                                                                                                                                      | `foot_placer.gd` (P10)                                                                                                   |
| Spring arm camera                                  | Node3D > SpringArm3D (Shape: SphereShape3D, Spring Length) > Camera3D (fq0hR2tIsRk 00:16:25)                                                                                                                                                                | `anim_tween.gd:spring_arm` (P12)                                                                                         |
| Preview poses                                      | Animation panel scrub; viewport camera bookmarks                                                                                                                                                                                                            | `gd_anim.pose_sheet` (P14)                                                                                               |
