# GUI paths (scenario-godot-rendering-lighting 0.1, Godot 4.7.2 editor)

These are the human or computer-use paths for the same procedures. Inspector section names follow the 4.7 editor. Project Settings paths need the **Advanced Settings** toggle (top right of the Project Settings window) for most rendering keys.

| Procedure      | Path                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| P1 renderer    | Project > Project Settings > General > Rendering > Renderer: Rendering Method (with `.mobile` and `.web` overrides through the override button). The top-right renderer dropdown in the editor switches it, and the editor restarts                                                                                                                                                                                                                                                                     |
| P1 physics     | Project Settings > Physics > 3D > Physics Engine: Jolt Physics                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| P1 driver      | Project Settings > Rendering > Rendering Device > Driver (.macos: metal or vulkan)                                                                                                                                                                                                                                                                                                                                                                                                                      |
| P2 audit       | No editor equivalent. Manual check: Scene dock, Filter Nodes by type (WorldEnvironment, Light3D, VoxelGI, LightmapGI)                                                                                                                                                                                                                                                                                                                                                                                   |
| P3 lookdev     | Scene > New Scene, then add WorldEnvironment (Inspector > Environment > New Environment) and a DirectionalLight3D. The 3D viewport toolbar "Toggle preview sunlight / environment" buttons only affect the editor; the game uses scene nodes                                                                                                                                                                                                                                                            |
| P3 judge light | 3D viewport > Perspective menu > Display Lighting (or Unshaded, Overdraw, Wireframe); View Frame Time for fps and GPU ms                                                                                                                                                                                                                                                                                                                                                                                |
| P4 parity      | Renderer dropdown (top right) and restart, or run with `--rendering-method mobile`. Unsupported features show a warning in the Output panel                                                                                                                                                                                                                                                                                                                                                             |
| P5 tonemap     | WorldEnvironment > Environment > Tonemap: Mode (Linear, Reinhard, Filmic, ACES, AgX), Exposure, White (AgX: Contrast)                                                                                                                                                                                                                                                                                                                                                                                   |
| P5 glow        | Environment > Glow: Enabled, Levels, Intensity, Strength, Bloom, Blend Mode (Screen by default), HDR Threshold                                                                                                                                                                                                                                                                                                                                                                                          |
| P6 VoxelGI     | Add VoxelGI, then size the box with the gizmo handles. Toolbar "Bake VoxelGI" in the 3D viewport while the node is selected. Inspector: Subdiv, Size, Data (Interior, Energy)                                                                                                                                                                                                                                                                                                                           |
| P7 lightmap    | Meshes: Inspector > GeometryInstance3D > Global Illumination > Mode Static, Lightmap Texel Scale. glTF: Import dock > Meshes > Light Baking: Static Lightmaps, Lightmap Texel Size, then Reimport. Lights: Light3D > Bake Mode (Disabled, Static, Dynamic). Add LightmapGI, then toolbar "Bake Lightmaps" (asks for a .lmbake save path the first time). Inspector: Tweaks > Quality, Supersampling, Bounces, Directional, Interior, Use Denoiser, Texel Scale; Environment > Mode; Gen Probes > Subdiv |
| P7 probes      | Add ReflectionProbe: Size, Box Projection, Interior, Enable Shadows, Update Mode                                                                                                                                                                                                                                                                                                                                                                                                                        |
| P8 SDFGI       | Environment > SDFGI: Enabled, Use Occlusion, Read Sky Light, Bounce Feedback, Cascades, Min Cell Size, Y Scale, Energy. Project Settings > Rendering > Global Illumination > SDFGI: Probe Ray Count, Frames To Converge, Frames To Update Lights                                                                                                                                                                                                                                                        |
| P9 cost        | Debugger > Visual Profiler (start, then read GPU ms per pass), or the viewport View Frame Time. Use the Vulkan driver: GPU time reads 0 on Metal                                                                                                                                                                                                                                                                                                                                                        |
| P10 fog        | Environment > Fog (Mode, Density, Light Color, Sun Scatter, Height, Height Density, Aerial Perspective) and Environment > Volumetric Fog (Enabled, Density, Albedo, Emission, Anisotropy, Length, Detail Spread, GI Inject). Light3D > Light > Volumetric Fog Energy. Project Settings > Rendering > Environment > Volumetric Fog: Volume Size, Volume Depth, Use Filter. Local fog: add FogVolume with a FogMaterial                                                                                   |
| P11 tiers      | Project Settings > Rendering > Anti Aliasing (MSAA 3D, Screen Space AA, TAA, Debanding), Scaling 3D (Mode, Scale, FSR Sharpness), Lights And Shadows (Directional Shadow Size and Soft Shadow Filter Quality; Positional Shadow Atlas Size and Quadrant Subdivs). DirectionalLight3D > Directional Shadow: Mode, Split 1 to 3, Blend Splits, Fade Start, Max Distance                                                                                                                                   |
| P12 compositor | WorldEnvironment (or Camera3D) > Compositor > New Compositor > Compositor Effects > Add Element > the effect script resource. The GLSL file must start with `#[compute]`; the editor imports it as an RDShaderFile and shows compile errors in its inspector                                                                                                                                                                                                                                            |
| P13 upscaler   | Project Settings > Rendering > Scaling 3D > Mode (Bilinear, FSR 1.0, FSR 2.2, MetalFX Spatial, MetalFX Temporal), or Viewport > Scaling 3D on a SubViewport                                                                                                                                                                                                                                                                                                                                             |
| Shadows        | Light3D > Shadow: Enabled, Bias, Normal Bias, Opacity, Blur; Omni: Shadow Mode (Dual Paraboloid, Cube)                                                                                                                                                                                                                                                                                                                                                                                                  |
| Grading        | Environment > Adjustments: Brightness, Contrast, Saturation, Color Correction (gradient or 3D LUT texture)                                                                                                                                                                                                                                                                                                                                                                                              |
| Day cycle      | AnimationPlayer > track on the sun parent's rotation, light_color and light_energy, plus Environment background_energy_multiplier and fog density                                                                                                                                                                                                                                                                                                                                                       |
