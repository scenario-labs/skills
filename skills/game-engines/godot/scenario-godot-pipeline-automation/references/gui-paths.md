# GUI paths (scenario-godot-pipeline-automation 0.1)

The same work through the Godot 4.7 editor, for a computer-use agent or a human. Menu names are from the 4.7 editor; paths not opened in a GUI session here are marked [docs].

| Work                                           | GUI path                                                                                                                                               | Scripted equivalent (this skill)                                     |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------- |
| Import settings of one GLB                     | Select the file in FileSystem > Import dock (next to Scene) > set options > Reimport                                                                   | ingest writes the `.glb.import` sidecar                              |
| Same settings on many files                    | Select several files > Import dock > set > Reimport; or Import dock > Preset > Set as Default for "Scene"                                              | sidecars per file; `[importer_defaults]` in `project.godot` (M3, M4) |
| Advanced scene import (per mesh, per material) | Double-click the GLB > Advanced Import Settings                                                                                                        | `_subresources` in the sidecar [docs]; post-import plugin            |
| Per-file pipeline options                      | Import dock shows `pipeline/*` when the Prop Pipeline plugin is enabled                                                                                | `prop_post_import.gd` `_get_import_options`                          |
| Post-import script on one file                 | Import dock > Import Script > Path                                                                                                                     | `import_script/path` in the sidecar (M2)                             |
| Texture compression                            | Select the extracted PNG > Import dock > Compress > Mode: VRAM Compressed; Normal Map: Enable; Process > Size Limit                                    | `prop_textures.gd`                                                   |
| Enable a plugin                                | Project > Project Settings > Plugins tab > Enable                                                                                                      | `[editor_plugins] enabled=PackedStringArray(...)`                    |
| Create a plugin                                | Project > Project Settings > Plugins > Create New Plugin                                                                                               | write `plugin.cfg` and the `@tool` script                            |
| Run an EditorScript                            | Script editor: File > Run (Ctrl+Shift+X, Cmd+Shift+X on macOS); FileSystem right-click > Run; command palette (Cmd+Shift+P) when it has a `class_name` | `editor=True` job calling `_run()`                                   |
| Tool button                                    | Inspector button from `@export_tool_button`                                                                                                            | call the Callable property                                           |
| Undo an editor script                          | Edit > Undo (Cmd+Z), History dock                                                                                                                      | `get_history_undo_redo(id).undo()`                                   |
| Reimport after an importer change              | FileSystem right-click > Reimport                                                                                                                      | `EditorFileSystem.scan()` then `reimport_files()`                    |
| Export                                         | Project > Export > Add preset > Resources tab: Export Mode, Filters to exclude files > Export Project / Export PCK/ZIP                                 | `ensure_preset`, `exclude_from_export`, `gd_run.export`              |
| Export templates                               | Editor > Manage Export Templates > Download and Install (4.7 also offers per-platform downloads)                                                       | `gd_env.install_templates()`                                         |
| gdUnit4 run                                    | GdUnit dock (bottom panel) > Run; right-click a test folder > Run Tests; right-click a function > Create Test [Sch 00:10:38]                           | `gp.run_gdunit4`                                                     |
| GUT run                                        | GUT bottom panel > Run All                                                                                                                             | `gd_run.run_tests(framework="gut")`                                  |
| GDExtension docs and reload                    | Restart the editor after replacing a library (Project > Reload Current Project)                                                                        | `--import` writes `extension_list.cfg`; restart Godot                |
| MCP server                                     | Client configuration (outside Godot); hybridindie's addon adds a dock                                                                                  | `gp.mcp_stdio` with a project-local build                            |
| Version control conflicts in scenes            | none in core; instance sub-scenes so related data stays together (Lilith Duncan, CAJ_iIedx_I [00:10:32])                                               | load every `.tscn` after a merge                                     |

Shortcuts on macOS use Cmd where Windows and Linux use Ctrl.
