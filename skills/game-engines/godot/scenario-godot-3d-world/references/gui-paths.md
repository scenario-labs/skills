# scenario-godot-3d-world GUI paths and code substitutes (Godot 4.7.2)

An agent cannot drag gizmos or paint in the viewport. Each row gives the human path in the editor and the substitute this skill runs in code.

| Task                                        | Editor path (human)                                                                                                                 | Code substitute (agent)                                                                                                                |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| Switch physics engine                       | Project > Project Settings > Physics > 3D > Physics Engine = Jolt Physics                                                           | `gd_env.set_project_setting(P, "physics/3d/physics_engine", '"Jolt Physics"')`, then `gd_world.physics_gate(P)`                        |
| Name collision layers                       | Project Settings > Layer Names > 3D Physics                                                                                         | `gd_world.set_layer_names(P, {1: "world", ...})`                                                                                       |
| CSG shapes and booleans                     | Add CSGCombiner3D, child CSGBox3D, Operation = Subtraction; drag the gizmo handles                                                  | `world_blockout.gd:_house` sets `size`, `operation`, `position`; `CSGPolygon3D.polygon` replaces drawing                               |
| Bake CSG                                    | select the CSG root > CSG menu in the viewport toolbar > Bake Mesh Instance / Bake Collision Shape (4.4+)                           | `bake_static_mesh()` and `bake_collision_shape()` (`world_blockout.gd:bake_all`)                                                       |
| MeshLibrary                                 | build a scene of MeshInstance3D (+ StaticBody3D) > Scene > Export As > MeshLibrary                                                  | `MeshLibrary.create_item / set_item_mesh / set_item_shapes` (`world_kit.gd:build_kit`)                                                 |
| GridMap painting                            | select GridMap > bottom GridMap panel: Paint, Fill, Pick; Ctrl + wheel changes the floor                                            | `set_cell_item(Vector3i, item, orientation)` from an ASCII plan (`build_grid`)                                                         |
| Terrain3D sculpt and paint                  | select Terrain3D > toolbar on the left of the viewport (Raise, Smooth, Paint, Spray); Inspector > Debug views                       | `data.import_images([height, control, color], ...)` from generated images (`world_terrain3d.gd:build`)                                 |
| Terrain3D region size                       | Inspector > Terrain3D > Regions > Region Size                                                                                       | `terrain.change_region_size(n)` once regions exist (`set("region_size")` is ignored in 1.0.2)                                          |
| Terrain3D texture painting                  | toolbar Paint Base Texture on a large area, then Spray Overlay; Autoshader tool per area (Tokisan YtiAI2F6Xkk 00:02:02 to 00:07:25) | a control map image passed to `import_images([height, control, color], ...)`; hand-painted detail stays a human step                   |
| Terrain3D collision mode                    | Inspector > Terrain3D > Collision > Mode                                                                                            | `terrain.collision.set_mode(FULL_GAME)` once in the tree                                                                               |
| Advanced Import Settings (per node physics) | double-click the .glb > select a mesh node > Physics > Generate                                                                     | `_subresources={"nodes": {"PATH:Node": {"generate/physics": true, "physics/body_type": 0, "physics/shape_type": 3}}}` in the `.import` |
| Import script                               | Import dock > Import Script > Path, Reimport                                                                                        | `gd_world.write_import_file(asset, {"import_script/path": ...})` before the first import                                               |
| Extract materials                           | Advanced Import Settings > Actions > Extract Materials                                                                              | `materials/extract` keys, or set materials in `post_import_prop.gd`                                                                    |
| Texture compression for extracted maps      | select the texture > Import dock > Compress Mode VRAM Compressed, Mipmaps on, Size Limit                                            | `gd_world.retune_textures(P)` then `gd_run.import_project(P)`                                                                          |
| Spring arm and camera framing               | drag the SpringArm3D and Camera3D gizmos                                                                                            | numeric properties in `build_player` (length 4.5, sphere r 0.3, pivot 1.5 m)                                                           |
| See collision shapes                        | Debug > Visible Collision Shapes                                                                                                    | `gd_run.capture_scene(..., extra_args=["--debug-collisions"])`                                                                         |
| Scatter trees                               | MultiMeshInstance3D > toolbar MultiMesh > Populate Surface                                                                          | `world_scatter.gd:scatter` (rule-based, windowed run)                                                                                  |
| Look at the level                           | the 3D viewport                                                                                                                     | `gd_run.capture_scene(P, scene, views=[...])` and a contact sheet, opened and looked at                                                |
