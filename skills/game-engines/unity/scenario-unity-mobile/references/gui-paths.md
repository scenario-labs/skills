# GUI paths (computer-use agent or human): the same mobile procedures through menus

Unity 6.3 (6000.3) on macOS. Menus are written as paths. Each row names the scripted equivalent in this skill so a GUI step can be checked afterwards with a job. Old tutorials say File > Build Settings: in 6.3 it is **File > Build Profiles**; Unity > Preferences is **Unity > Settings** on macOS.

## Platform and build

| Task                          | GUI path                                                                                                                                                                                                               | Scripted equivalent                                                                                                                  |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| Install Android / iOS support | Unity Hub > Installs > 6000.3.21f1 > gear > Add modules > Android Build Support (+ OpenJDK, Android SDK & NDK Tools) / iOS Build Support                                                                               | none (Hub); check with `ut_env.find_editor()["modules"]`                                                                             |
| Switch platform               | File > Build Profiles > Android (or iOS) > Switch Platform                                                                                                                                                             | launch every job with `build_target="Android"` / `"iOS"` (target-switching APIs don't take effect inside a batch script: 6.3 Manual) |
| Build an AAB                  | File > Build Profiles > Android > tick Build App Bundle (Google Play) (hidden while Export Project is on), untick Development Build > Build                                                                            | `MobileBuild.BuildAndroid` (`EditorUserBuildSettings.buildAppBundle = true`)                                                         |
| Debug symbols                 | File > Build Profiles > Android > Debug Symbols: Level Public/Debugging (symbol table / full), Output App Bundle, .zip, or both                                                                                        | `UnityEditor.Android.UserBuildSettings.DebugSymbols.level/.format` (`MobileBuild.ApplyAndroidRelease`, `symbols`)                    |
| Asset Import Overrides        | File > Build Profiles > Android > Asset Import Overrides > Texture Compression: No Override for store builds                                                                                                           | audited by `MobileBuild.AuditPlayerSettings` (`mobile.build.force_uncompressed`)                                                     |
| Export Xcode project          | File > Build Profiles > iOS > Build > pick folder > Replace (or Append for the same Unity iOS version)                                                                                                                 | `MobileBuild.BuildIos` (`append=false` = Replace)                                                                                    |
| Archive and upload iOS        | Xcode > open `Unity-iPhone.xcodeproj` > Signing & Capabilities (team) > Product > Archive > Organizer > Distribute App                                                                                                 | human with the Apple account; agent stops after `xcode_facts` (optionally `xcode_compile_unsigned`)                                  |
| Upload to Play                | play.google.com/console > app > Testing > Internal testing > Create release > upload the .aab (+ symbols zip if not embedded)                                                                                          | human or computer-use; `aab_facts` + `aab_findings` + `bundletool_sizes` before                                                      |
| iOS size per device           | Xcode > Organizer > Distribute App > Custom > Release Testing > App Thinning: All compatible device variants > Export (writes App Thinning Size Report.txt) [added]                                                    | `ios_archive_plan` export_size_report (method release-testing, thinning `<thin-for-all-variants>`), `app_thinning_report`            |
| Play console declarations     | App content (policy section): Ads, Advertising ID (API 33+), Data safety, Content rating, Target audience, Privacy policy; App signing: enroll the upload key in Play App Signing [verify labels: the console changes] | human; answers from the SDK vendors' data guides (UXl_C3ZnRLc [00:02:28])                                                            |

## Player Settings (Edit > Project Settings > Player)

| Setting                  | Android path                                                                                                                                                                        | iOS path                                                       | Scripted                                                                                                                       |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Package name / Bundle ID | Other Settings > Identification > Package Name (Override Default)                                                                                                                   | Other Settings > Identification > Bundle Identifier            | `PlayerSettings.SetApplicationIdentifier(NamedBuildTarget.Android/iOS, ...)`                                                   |
| Version, version code    | Other Settings > Identification > Version, Bundle Version Code                                                                                                                      | Version, Build                                                 | `PlayerSettings.bundleVersion`, `Android.bundleVersionCode`, `iOS.buildNumber`                                                 |
| Min / target API         | Other Settings > Identification > Minimum API Level (25+ in 6.3), Target API Level (36 for Play)                                                                                    | Other Settings > Target minimum iOS Version (15.0+)            | `Android.minSdkVersion`, `Android.targetSdkVersion = AndroidApiLevel36`, `iOS.targetOSVersionString`                           |
| IL2CPP, ARM64            | Other Settings > Configuration > Scripting Backend IL2CPP, then Target Architectures ARM64 (grayed out under Mono)                                                                  | IL2CPP only                                                    | `SetScriptingBackend(Android, IL2CPP)`, `Android.targetArchitectures = ARM64`                                                  |
| Stripping                | Other Settings > Optimization > Managed Stripping Level (Minimal to start), Strip Engine Code                                                                                       | same + Script Call Optimization "Fast but no exceptions"       | `SetManagedStrippingLevel`, `stripEngineCode`, `iOS.scriptCallOptimization`                                                    |
| Texture formats          | Other Settings > Rendering > Texture Compression Formats (first = default; AAB targeting uses the list)                                                                             | n/a (per-texture overrides)                                    | `PlayerSettings.Android.textureCompressionFormats`                                                                             |
| Graphics APIs            | Other Settings > Rendering > untick Auto Graphics API, order Vulkan / OpenGLES3                                                                                                     | Metal only                                                     | `SetUseDefaultGraphicsAPIs(Android, false)`, `SetGraphicsAPIs`                                                                 |
| Safe area                | Resolution and Presentation > Render outside safe area                                                                                                                              | (full screen by default)                                       | `PlayerSettings.Android.renderOutsideSafeArea`                                                                                 |
| Keystore                 | Publishing Settings > Keystore Manager > Keystore > Create New (Anywhere / In Dedicated Location) > Add Key; then Custom Keystore + passwords (re-enter after every Editor restart) | Signing: Other Settings > Automatically Sign / Signing Team ID | `ut_mobile.make_keystore` (keytool) + env vars read by `MobileBuild.BuildAndroid`                                              |
| Minify, Gradle templates | Publishing Settings > Minify (Release), Custom Main Gradle Template, Custom Proguard File                                                                                           | n/a                                                            | `Android.minifyRelease`; templates are files in `Assets/Plugins/Android/`                                                      |
| Frame Timing Stats       | Other Settings > Rendering > Frame Timing Stats                                                                                                                                     | same                                                           | `PlayerSettings.enableFrameTimingStats` (set by `BuildAndroid`/`BuildIos` for development builds; `DeviceSoakLogger` needs it) |

## Textures

| Task                       | GUI path                                                                                                                                                                                                                           | Scripted                                                     |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| Per-platform override      | select texture > Inspector > Android tab (and iOS tab) > Override For Android > Max Size, Format (ASTC 4x4 / 6x6 / 8x8, ASTC HDR 6x6) > Apply                                                                                      | `MobileTextures.FixTextures`                                 |
| Read/Write, mipmaps        | Inspector > Advanced > Read/Write; Generate Mip Maps (off for Sprite/UI)                                                                                                                                                           | same job                                                     |
| Check the imported format  | Inspector preview footer shows e.g. "1024x1024 RGBA Compressed ASTC 6x6 sRGB 0.6 MB" (for the active platform)                                                                                                                     | `MobileTextures.ImportedFormats` with `build_target`         |
| Audio import               | select clip > Inspector > Force To Mono; Default (or Android / iOS tab, Override) > Load Type, Compression Format (ADPCM, Vorbis), Quality, Sample Rate Setting Override 22050 Hz > Apply; footer shows Original and Imported Size | `MobileAudio.FixAudio`, `ImportedAudio`                      |
| Mesh Read/Write            | select model > Inspector > Model > Read/Write, Mesh Compression, Import BlendShapes                                                                                                                                                | `MobileAudio.AuditMeshes`                                    |
| Keep new imports compliant | Edit > Project Settings > Preset Manager (default presets per importer type and folder filter)                                                                                                                                     | `MobileImportRules` + `Assets/AgentMobile/import_rules.json` |
