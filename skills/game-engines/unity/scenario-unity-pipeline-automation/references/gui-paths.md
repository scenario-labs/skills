# GUI paths for the pipeline procedures (computer-use agent or human)

Unity 6.3 on macOS (Cmd for Ctrl). Menus were reorganized in 6.1 (Package Manager under Window > Package Management); verify labels on the installed editor before scripting clicks. Every row has a scripted equivalent in `procedures.md`: prefer it; use the GUI path when the user's editor must show the result, or for surfaces with no API.

| Task                                                           | GUI path                                                                                                                                              | Scripted equivalent                                                                                                                                                                        |
| -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Add Addressables (pin 2.9.1)                                   | Window > Package Management > Package Manager > + > Add package by name > `com.unity.addressables`                                                    | `ut_pipeline.add_packages(P, {"com.unity.addressables": "2.9.1"})` before the editor opens                                                                                                 |
| Import settings of one texture or model                        | select it in the Project window > Inspector > Apply                                                                                                   | `PropImportPostprocessor` (rules JSON)                                                                                                                                                     |
| Default import settings without code (static values)           | preset Inspector > Add to TextureImporter default; or Edit > Project Settings > Preset Manager (filter such as `_N`, or `glob:` patterns)             | postprocessor or presets-by-folder postprocessor                                                                                                                                           |
| Partial preset                                                 | preset Inspector > three dots > Exclude All Properties, right-click a property > Include Property                                                     | `Preset` API [verify on 6.3]                                                                                                                                                               |
| Reimport a folder or everything                                | right-click > Reimport; Assets > Reimport All                                                                                                         | `AssetDatabase.ImportAsset(path)`; rules edit triggers it                                                                                                                                  |
| Refresh after files changed on disk                            | Assets > Refresh (Cmd+R)                                                                                                                              | `AssetDatabase.Refresh()`; each batch job refreshes at start                                                                                                                               |
| Prove importers deterministic                                  | none used (command-line flag; a GUI path was not checked)                                                                                             | `up.consistency_check(P)` (`-consistencyCheck`, P19)                                                                                                                                       |
| How many assets a step imported                                | Editor.log after a refresh: `Imports: total=N (actual=, local cache=, cache server=)`                                                                 | `up.counters(P)`, `import_assetdb`, `remap_assetdb` (P20)                                                                                                                                  |
| Remap FBX materials                                            | select the FBX > Inspector > Materials tab > Location: Use Embedded Materials > On Demand Remap                                                       | `ModelImporter.AddRemap` + `SaveAndReimport`                                                                                                                                               |
| Create a Prefab Variant                                        | drag the FBX into the scene, add components, drag it back into the Project window > Prefab Variant; or right-click a prefab > Create > Prefab Variant | `PrefabUtility.SaveAsPrefabAsset` on a model prefab instance                                                                                                                               |
| Edit a prefab asset                                            | double-click it (Prefab Mode), edit, Save                                                                                                             | `LoadPrefabContents` / `SaveAsPrefabAsset` / `UnloadPrefabContents`                                                                                                                        |
| See or apply prefab overrides                                  | select the instance > Inspector > Overrides dropdown                                                                                                  | `PrefabUtility.GetPropertyModifications`, `ApplyPrefabInstance`                                                                                                                            |
| Undo history                                                   | Window > General > Undo History (6.1 menu) ; Edit > Undo (Cmd+Z)                                                                                      | `Undo.GetCurrentGroupName`, `Undo.PerformUndo`                                                                                                                                             |
| Addressables Groups window (groups, labels, addresses)         | Window > Asset Management > Addressables > Groups; Inspector "Addressable" checkbox; Labels column gear to add labels                                 | `AddressablesJobs.AssignGroups` (`CreateGroup`, `CreateOrMoveEntry`, `SetAddress`, `SetLabel`)                                                                                             |
| Group bundle mode and compression                              | select a group asset > Inspector > Content Packing & Loading > Bundle Mode, Compression                                                               | `BundledAssetGroupSchema.BundleMode`, `.Compression`                                                                                                                                       |
| Auto grouping by dependency graph (2.9.1)                      | Window > Asset Management > Addressables > Auto Group Generator                                                                                       | no public API; `AssignGroups(layout="condition")`                                                                                                                                          |
| Analyze duplicates                                             | Window > Asset Management > Addressables > Analyze > Check Duplicate Bundle Dependencies > Analyze / Fix Selected Rules                               | `CheckBundleDupeDependencies.RefreshAnalysis(settings)` / `FixIssues` (`layout="isolate"`)                                                                                                 |
| What a build scene pulls in                                    | Project window > right-click the scene > Select Dependencies (then look for Addressable assets)                                                       | `up.hard_references(P)` (P22)                                                                                                                                                              |
| Build Addressables content                                     | Groups window > Build > New Build > Default Build Script; Build > Clear Build Cache                                                                   | `AddressablesJobs.BuildContent`                                                                                                                                                            |
| Build layout report                                            | Addressables preferences > Debug Build Layout; Window > Asset Management > Addressables > Build Reports                                               | `ProjectConfigData.GenerateBuildLayout = true`; `BuildLayout.Open(...)`                                                                                                                    |
| Build Addressables on Player Build                             | select `AddressableAssetSettings` > Inspector > Build > Build Addressables on Player Build                                                            | `settings.BuildAddressablesWithPlayerBuild`                                                                                                                                                |
| Content update of a released build                             | Window > Asset Management > Addressables > Groups > Tools > Check for Content Update Restrictions; Build > Update a Previous Build                    | `ContentUpdateScript` [verify] with the archived state file                                                                                                                                |
| Addressables runtime view                                      | Window > Analysis > Profiler > Addressables module                                                                                                    | player smoke `bundles_loaded` / `bundles_after_release`                                                                                                                                    |
| Create a Build Profile                                         | File > Build Profiles > Add Build Profile > Platform Browser > Add Build Profile                                                                      | `PipelineBuild.CreateBuildProfile` with `template` (public `AssetDatabase.CopyAsset`), else the 6.3 internal API; `unity build --create-profile`; `BuildProfile.CreateBuildProfile` (6.5+) |
| Copy a committed profile                                       | Project window > select the profile asset > Edit > Duplicate (Cmd+D)                                                                                  | `CreateBuildProfile {template: ...}` (P13)                                                                                                                                                 |
| Profile overrides (scenes, defines, Player, Quality, Graphics) | File > Build Profiles > select > Add Settings                                                                                                         | `BuildProfile.scenes`, `.overrideGlobalScenes`, `.scriptingDefines`, `CreateComponent`                                                                                                     |
| Switch profile, build                                          | File > Build Profiles > select > Switch Profile > Build                                                                                               | `-activeBuildProfile <asset>` at launch + `BuildPlayerWithProfileOptions`                                                                                                                  |
| Scene list of the build                                        | File > Build Profiles > Scene List                                                                                                                    | `EditorBuildSettings.scenes`                                                                                                                                                               |
| Test Runner, create a test assembly                            | Window > General > Test Runner; Assets > Create > Testing > Test Assembly Folder                                                                      | `ut_run.run_tests`; tests in Assembly-CSharp-Editor or an asmdef written as JSON                                                                                                           |
| Run one category                                               | Test Runner > category dropdown > Run Selected                                                                                                        | `-testCategory PipelinePreBuild`                                                                                                                                                           |
| Unity Accelerator (shared import cache)                        | Settings > Asset Pipeline > Cache Server (verify label on 6.3)                                                                                        | `-EnableCacheServer -cacheServerEndpoint host:10080`, `-cacheServerWaitForUploadCompletion` with `-quit`; `ACCELERATOR=` in `ci/pipeline.sh` (P26)                                         |
| Release build provenance                                       | Finder: `<Game>.app` > Show Package Contents > `unity-build.provenance.json` (after `unity build`)                                                    | `up.provenance(app)`, `up.release_ready(repo, app)` (P23)                                                                                                                                  |
| Personal license for a CI Mac                                  | Unity Hub > sign in; Hub > Preferences > Licenses (every 30 days)                                                                                     | none for Personal; paid seats: `unity license activate` / `-serial`, then return                                                                                                           |
| GitHub secrets                                                 | GitHub repo > Settings > Secrets and variables > Actions > New repository secret                                                                      | `gh secret set NAME`                                                                                                                                                                       |
| Custom agent command registered                                | Pipeline menu (after `com.unity.pipeline`), `unity command` lists it                                                                                  | `[CliCommand]` + `unity command recompile`                                                                                                                                                 |
