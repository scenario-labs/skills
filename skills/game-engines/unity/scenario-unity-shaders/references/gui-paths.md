# GUI paths for the shading procedures (computer-use agent or human)

Unity 6.3 (6000.3.21f1) on macOS (Cmd for Ctrl). Labels from the installed editor and packages where noted [verified: installed]; verify others before scripting clicks. The scripted route is in `procedures.md`; the GUI is required for what has no scripting surface (wiring Shader Graph nodes, Graph Settings, the Render Graph Viewer and Frame Debugger).

## Shader Graph (visual editor: the agent's gap)

| Task                                                                                                                                                   | GUI path                                                                                                                                                                                         | Scripted substitute                                                                                                                                                                                                                                                                                                     |
| ------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| New graph                                                                                                                                              | Assets > Create > Shader Graph > URP > Lit / Unlit / Fullscreen Shader Graph [verified: installed menu items]; 6.3 also offers templates in the Create Shader Graph from template window         | duplicate an existing graph: `ShaderGraphJobs.DuplicateGraph`                                                                                                                                                                                                                                                           |
| Import a sample (Custom Lighting, etc.)                                                                                                                | Window > Package Management > Package Manager > Shader Graph > Samples > Import                                                                                                                  | `ShaderGraphJobs.ImportPackageSample` (copies `Samples~` with .meta)                                                                                                                                                                                                                                                    |
| Add a node                                                                                                                                             | open the graph, Space (Create Node), search                                                                                                                                                      | none; ask for a one-time wiring or reuse a graph                                                                                                                                                                                                                                                                        |
| Custom Function node                                                                                                                                   | Create Node > Utility > Custom Function; Graph Inspector > Node Settings: Type File, Source (drag the .hlsl), Name WITHOUT `_float`, Inputs and Outputs with + in the function's parameter order | edit the `.hlsl` only; repoint an existing node: `ut_shaders.shadergraph_repoint_custom_function` (editor closed)                                                                                                                                                                                                       |
| Convert to Sub Graph                                                                                                                                   | select nodes > right-click > Convert To Sub Graph                                                                                                                                                | none                                                                                                                                                                                                                                                                                                                    |
| Graph Settings (Surface Type, Render Face Both, Alpha Clipping, Allow Material Override, Keep Lighting Variants, Default Decal Blending, Default SSAO) | Graph Inspector > Graph Settings                                                                                                                                                                 | URP target fields by text edit, editor closed: `ut_shaders.shadergraph_set_target_settings(p, alpha_clip=, allow_material_override=, surface_type=, render_face=, cast_shadows=)` (P17); custom lighting in 6.3: Unlit + Keep Lighting Variants ON, Default Decal Blending and Default SSAO OFF (subtarget fields, GUI) |
| Blackboard property or keyword                                                                                                                         | Blackboard > + > Float / Color / Texture2D / Keyword (Boolean or Enum); Definition, Scope, Stages, Generate Material Property                                                                    | set values: `Material.SetFloat` with the Reference name (`ShaderProperties` lists them); keywords: `EnableKeyword("_REF")`, Enum `"_REF_SUFFIX"`                                                                                                                                                                        |
| View generated code                                                                                                                                    | select the .shadergraph > Inspector > View Generated Shader [verified: installed `ShaderGraphImporterEditor.cs`]                                                                                 | `ShaderGraphJobs.GeneratedCode` writes the same text to the job's `out/generated/` (P17); `ShaderJobs.ValidateShaders` for compile messages                                                                                                                                                                             |

## Materials and shaders

| Task                          | GUI path                                                                                                                                                    | Scripted substitute                                                                                             |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| New hand-written shader       | Assets > Create > Shader > URP Unlit Shader [verified: installed template]                                                                                  | write the `.shader` text; `ValidateShaders`                                                                     |
| SRP Blit shader (full-screen) | Assets > Create > Shader > SRP Blit Shader [verified: installed Core RP template]                                                                           | `AgentGrayscale.shader` pattern                                                                                 |
| Compute shader                | Assets > Create > Shader > Compute Shader                                                                                                                   | write the `.compute`; `ValidateShaders` lists its messages                                                      |
| Shader facts                  | select the shader > Inspector: SRP Batcher line, keywords (Overridable / Not Overridable), Compile and show code (platform dropdown, Show, Preprocess only) | `ValidateShaders` (`srp_batcher` after a render via `Shots`, `inspector_variant_counts`)                        |
| Material keywords and values  | select the material > Inspector                                                                                                                             | `ShaderJobs.SetupMaterials` (a `[Toggle(KW)]` float does not enable the keyword from script: add `keywords_on`) |
| Texture as normal map         | select the texture > Texture Type: Normal map; sRGB off for data textures                                                                                   | `ShaderJobs.ImportTextures`                                                                                     |

## URP settings a shader depends on

| Task                                   | GUI path                                                                                                                                          | Scripted substitute                                                                                   |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Depth / Opaque Texture                 | select the URP asset (Assets/Settings/PC_RPAsset, Mobile_RPAsset) > Rendering > Depth Texture / Opaque Texture                                    | `ShaderJobs.ConfigureUrp {"depth_texture": true}` for each asset                                      |
| Rendering path, Depth Priming          | select the Universal Renderer Data (Assets/Settings/PC_Renderer) > Rendering > Rendering Path; Depth Priming Mode                                 | `ConfigureUrp {"rendering_mode", "depth_priming"}`                                                    |
| Add a renderer feature                 | Universal Renderer Data > Add Renderer Feature > (Full Screen Pass Renderer Feature, Screen Space Ambient Occlusion, custom)                      | `RendererFeatureJobs.AddFeature` (writes the list AND the map)                                        |
| Full Screen Pass fields                | the feature in the renderer Inspector: Pass Material, Injection Point, Requirements, Fetch Color Buffer; Pass index under ⋮ > Advanced Properties | `AddFeature` fields `passMaterial`, `injectionPoint`, `requirements`, `fetchColorBuffer`, `passIndex` |
| Toggle a feature                       | checkbox on the feature header                                                                                                                    | `RendererFeatureJobs.SetFeatureActive`, or a `Shots` op                                               |
| Volume and profile for a custom effect | GameObject > Volume > Global Volume; Create > Rendering > Volume Profile; Add Override                                                            | `VolumeProfile.Add<T>()`, `overrideState` (not scripted in this skill)                                |

## Variants and stripping

| Task                                                      | GUI path                                                                                                                                                                                                                 | Scripted substitute                                                                                                                                        |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Strict Shader Variant Matching                            | Edit > Project Settings > Player > Other Settings > Strict Shader Variant Matching                                                                                                                                       | `VariantJobs.StrippingSettings {"strict_variant_matching": true}`                                                                                          |
| Log Shader Compilation                                    | Edit > Project Settings > Graphics > Shader Loading > Log Shader Compilation                                                                                                                                             | `StrippingSettings {"log_shader_compilation": true}`                                                                                                       |
| Shader Build Settings (keyword Type Override, exclusions) | Edit > Project Settings > Graphics > Shader Build Settings > +, type the full set with `_`, Type Override or untick keywords, Apply; per build profile in File > Build Profiles                                          | `VariantJobs.KeywordOverrides` (`EditorGraphicsSettings.SetShaderBuildSettings`, writes the active set; P15); build-profile overrides stay a GUI step here |
| URP stripping options                                     | Edit > Project Settings > Graphics > URP section: Strip Unused Variants, Strip Unused Post Processing Variants, Strip Screen Coord Override Variants; Shader Stripping: Export Shader Variants, Shader Variant Log Level | read by `StrippingSettings`                                                                                                                                |
| Variant collection from the editor                        | Graphics > Shader Loading > Save to asset...                                                                                                                                                                             | not recommended as a strip whitelist (Carotenuto)                                                                                                          |
| Post-processing variants kept                             | Graphics > URP > Strip Unused Post Processing Variants; the Default Volume Profile (Graphics > URP)                                                                                                                      | `VariantJobs.PostProcessingAudit` lists every VolumeProfile under Assets/ and what it keeps (P16)                                                          |
| PSO trace and warm-up                                     | File > Build Profiles > Development Build (tracing needs it), Autoconnect Profiler for `SendToEditor`; Profiler > search `Shader.CreateGPUProgram` in gameplay frames                                                    | `PsoJobs.BuildPsoScene`, `ut_run.build(development=True)`, `ut_shaders.run_pso_player` trace / cold / warm, `pso_gate` (P18)                               |

## Debuggers (GUI only)

| Window                           | Path                                                                                                                                                              | Scripted proxy                                                                                              |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Render Graph Viewer              | Window > Analysis > Render Graph Viewer [verified: installed menu]; pick the camera, refresh after changes; green read, red write, blue line merged, globe global | readback of on/off captures; pass names via `ProfilingSampler`                                              |
| Frame Debugger                   | Window > Analysis > Frame Debugger; "(RP n:m)" labels show native render passes                                                                                   | none                                                                                                        |
| Rendering Debugger               | Window > Analysis > Rendering Debugger (Map Overlays: Depth, Normals; Overdraw)                                                                                   | a full-screen view shader (the ShowNormals test shader)                                                     |

| Xcode Metal capture (macOS, iOS) | Xcode > Debug > Capture GPU Workload on a development player                                                                                                      | outside Unity                                                                                               |
