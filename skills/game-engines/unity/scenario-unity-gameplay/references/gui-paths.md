# GUI paths (scenario-unity-gameplay): the same procedures for a computer-use agent or a human

Unity 6.3 menu names (6.1 reorganized several menus; Build Settings is File > Build Profiles). Each row names the scripted equivalent used in `procedures.md`, so an agent can switch channel without changing the plan.

## Physics

| Task                                                                                                                                | GUI path                                                                                        | Scripted equivalent                                                                                                                                                                              |
| ----------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Fixed Timestep, Maximum Allowed Timestep                                                                                            | Edit > Project Settings > Time                                                                  | `SerializedObject` on `ProjectSettings/TimeManager.asset` (`Fixed Timestep.m_Count` at `m_Rate`, `Maximum Allowed Timestep`); the `Time.*` statics do not persist from an editor job (measured)  |
| Layers                                                                                                                              | Edit > Project Settings > Tags and Layers > User Layers                                         | `GameplaySetup.EnsureLayers` (SerializedObject on TagManager)                                                                                                                                    |
| Layer Collision Matrix                                                                                                              | Edit > Project Settings > Physics > Settings > Shared tab > Layer Collision Matrix              | `Physics.IgnoreLayerCollision` (persists, measured)                                                                                                                                              |
| Simulation Mode, Auto Sync Transforms, Broad phase Type, Default Solver Iterations, Reuse Collision Callbacks, Queries Hit Triggers | Edit > Project Settings > Physics > Settings > GameObject tab                                   | `SerializedObject` on `DynamicsManager.asset` (`m_SimulationMode`, `m_AutoSyncTransforms`, `m_BroadphaseType`, `m_DefaultSolverIterations`, `m_ReuseCollisionCallbacks`, `m_QueriesHitTriggers`) |
| Prebake Collision Meshes                                                                                                            | Edit > Project Settings > Player > Other Settings                                               | `PlayerSettings` (read in audits)                                                                                                                                                                |
| Rigidbody Interpolate, Collision Detection                                                                                          | Rigidbody Inspector                                                                             | `Rigidbody.interpolation`, `collisionDetectionMode`                                                                                                                                              |
| Mesh Collider cooking                                                                                                               | Mesh Collider Inspector > Cooking Options                                                       | `MeshCollider.cookingOptions`                                                                                                                                                                    |
| Sleep states, contacts                                                                                                              | Window > Analysis > Physics Debugger                                                            | `Rigidbody.IsSleeping()` sampled in a Play Mode test                                                                                                                                             |
| Queries seeing moved colliders                                                                                                      | (no setting: Auto Sync Transforms stays off, deprecated)                                        | `Physics.SyncTransforms()` after moving colliders by transform (`QueryTests.MovedStaticColliderNeedsSyncTransforms`)                                                                             |
| Physics step count per frame                                                                                                        | Window > Analysis > Profiler > CPU Usage > Hierarchy, search `Physics.Processing`, Calls column | `StepProbe` Play Mode test (steps per frame, game time per real time)                                                                                                                            |
| Broad phase pairs, contacts                                                                                                         | Profiler > Physics module                                                                       | not scripted here (read the module in a GUI session)                                                                                                                                             |

## AI navigation (AI Navigation 2.0.14)

| Task                                      | GUI path                                                                                                                          | Scripted equivalent                                                                                                                     |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Agent types (radius, height, step, slope) | NavMesh Agent Inspector > Agent Type dropdown > Open Agent Settings (Navigation window, Agents tab)                               | `NavMesh.GetSettingsByID`, `NavMesh.CreateSettings` [asm]; persistence not tested here                                                  |
| Area types and costs                      | Navigation window > Areas tab                                                                                                     | `NavMesh.SetAreaCost`, `NavMeshAgent.SetAreaCost`                                                                                       |
| Bake                                      | GameObject > AI > NavMesh Surface, then Bake on the component                                                                     | `GameplayScenes.BakeAndSave` (`BuildNavMesh()` + `AssetDatabase.CreateAsset(navMeshData)` + save scene)                                 |
| Voxel size, tile size, HeightMesh         | NavMesh Surface > Advanced > Override Voxel Size, Override Tile Size, Build Height Mesh; Show HeightMesh in the surface Inspector | `overrideVoxelSize`, `voxelSize`, `overrideTileSize`, `tileSize`, `buildHeightMesh` (tread error by `SamplePosition`, `NavExtrasTests`) |
| What gets baked                           | NavMesh Surface > Object Collection (Collect Objects, Include Layers), Use Geometry                                               | `collectObjects`, `layerMask`, `useGeometry`                                                                                            |
| Exclude or mark props                     | Add Component > Navigation > NavMesh Modifier (Mode Remove Object, Override Area Not Walkable)                                    | `NavMeshModifier.ignoreFromBuild`, `overrideArea`, `area`, `applyToChildren`                                                            |
| Links over gaps                           | GameObject > AI > NavMesh Link; drag the yellow end handles and orange width dots                                                 | `NavMeshLink` fields (start/end point or transform, width, bidirectional, area) [package API, not run here]                             |
| See the NavMesh                           | Scene view > AI Navigation overlay > Show NavMesh Surface (gizmos on), Show HeightMesh, Show Path Polygons, Show Avoidance        | `GameplayScenes.NavMeshOverlay` + `AgentCapture.CaptureViews` (top-down)                                                                |
| Convert old scenes                        | Window > AI > Navigation Updater                                                                                                  | none; convert in a GUI session                                                                                                          |
| Carving obstacle                          | Add Component > Navigation > NavMesh Obstacle > Carve, Carve Only Stationary, Time To Stationary (0.5 s)                          | `NavMeshObstacle.carving`, `carveOnlyStationary`, `carvingTimeToStationary`; queries see the carve next frame                           |
| Agent and Animator coupling               | Animator Inspector > Apply Root Motion; NavMesh Agent (no toggle for updatePosition)                                              | `AgentLocomotionSync` (`agent.updatePosition`, `OnAnimatorMove`)                                                                        |
