## 4. Where sources disagree (and the deciding condition)

| Topic                             | Side A                                                                            | Side B                                                          | Decides                                                                                                                                                                                                 |
| --------------------------------- | --------------------------------------------------------------------------------- | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Idle in the locomotion tree       | at the origin (iHeartGameDev)                                                     | own state, tree starts at a slow walk (Ketra)                   | root motion or dissimilar idle: own state                                                                                                                                                               |
| Root motion rig type              | Humanoid required (Ketra)                                                         | Generic works via Root Node, costs more (6.3 Manual)            | the Manual; Humanoid when retargeting                                                                                                                                                                   |
| Head vs chest aim order           | head first (Brackeys)                                                             | body first (Code Monkey, depth-first rule)                      | body first: measured 0.0 vs 17.9 deg                                                                                                                                                                    |
| CM2 project                       | stay, not worth it (git-amend)                                                    | upgrade in two passes (CM3 manual)                              | new 6.3 work and anything moving to 6.6: CM3                                                                                                                                                            |
| Culling                           | Cull Completely always (Manual)                                                   | Cull Update Transforms for offscreen root-motion movers [added] | root-motion NPCs that must keep traveling offscreen                                                                                                                                                     |
| Idle rotation and XZ Based Upon   | Original (Ketra, Mixamo idles)                                                    | Body Orientation / Center of Mass (Manual default, mocap)       | where the pose must sit: Original for clips authored at the origin facing forward, Body Orientation for segments cut from long takes; neither changes drift once the axis is baked (measured: 0 m both) |
| Who owns a jump's vertical motion | the script (scripted height; clip Y unbaked + Feet, its vertical delta discarded) | the clip (`gravityWeight` blend, [added])                       | gameplay-tuned jump heights vs authored drops, vaults and climbs                                                                                                                                        |
| Blend hint for a flipping pair    | IgnoreTarget (XTVzs4B1d7I [00:13:32], first example)                              | Cylindrical Position (XTVzs4B1d7I; u0a1F6BlczE [00:20:49])      | cameras on opposite sides of the target: Cylindrical (measured: IgnoreTarget stopped the flip but still passed 0.5 m from the target)                                                                   |
