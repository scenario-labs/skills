# GUI paths for the lead's procedures (for a computer-use agent or a human)

Unity 6.3 menu names on macOS (Cmd for Ctrl). Menus moved in 6.1 (Package Manager under Window > Package Management); verify labels on the installed editor before scripting clicks.

| Task                                                          | GUI path                                                                                | Scripted equivalent                                                                                 |
| ------------------------------------------------------------- | --------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| Sign in and refresh the Personal license (every 30 days)      | Unity Hub > sign in; Hub > Preferences > Licenses                                       | none for Personal (`ut_env.license_ok()` reads the date)                                            |
| Add modules (Web, iOS, Android)                               | Unity Hub > Installs > 6000.3.21f1 > Add modules                                        | `Unity Hub -- --headless install-modules --version 6000.3.21f1 -m webgl ios android ...` (README)   |
| Build Profiles, platform switch, build                        | File > Build Profiles > select > Switch Profile > Build                                 | `ut_run.build(P, target)` (`-buildTarget` at launch)                                                |
| Scene list for builds                                         | File > Build Profiles > Scene List                                                      | `EditorBuildSettings.scenes` in a job                                                               |
| Player settings (Web compression, backend)                    | Edit > Project Settings > Player > Web / macOS                                          | `PlayerSettings.WebGL.compressionFormat`, `PlayerSettings.SetScriptingBackend`                      |
| Enter Play Mode setting                                       | Edit > Project Settings > Editor > Enter Play Mode Settings > "When entering Play Mode" | `EditorSettings.enterPlayModeOptionsEnabled` / `enterPlayModeOptions` (reported by `AgentJob.Echo`) |
| Active Input Handling                                         | Edit > Project Settings > Player > Other Settings > Active Input Handling (restart)     | reported by `AgentJob.Echo`                                                                         |
| Test Runner                                                   | Window > General > Test Runner (EditMode, PlayMode tabs)                                | `ut_run.run_tests`                                                                                  |
| Profiler, attach to player                                    | Window > Analysis > Profiler                                                            | `AgentProfile.PlayModeTimings`, player `-profiler-enable -profiler-log-file`                        |
| Frame Debugger                                                | Window > Analysis > Frame Debugger                                                      | no public API; ProfilerRecorder render counters as proxy                                            |
| Console (compile errors)                                      | Window > General > Console                                                              | `ut_run` log scan; bridge heartbeat `compile_errors`                                                |
| Package Manager (add `com.unity.pipeline`, Cinemachine 3.1.7) | Window > Package Management > Package Manager > + > Add package by name                 | `ut_live.pipeline_install(P)`; `Packages/manifest.json`                                             |
| Pipeline menu (after the package)                             | Pipeline menu in the editor menu bar (Unity CLI intro, DgNrgZeJOxQ [00:01:38])          | `unity command ...`                                                                                 |
| Unity MCP Server settings (deprecated)                        | Edit > Project Settings > AI > Unity MCP Server                                         | `unity mcp`                                                                                         |
| Safe Mode dialog                                              | appears at editor start with compile errors: fix scripts, or enter Safe Mode            | fix the `.cs`, restart by PID                                                                       |
| Lighting settings asset                                       | Window > Rendering > Lighting > New Lighting Settings                                   | `Lightmapping.lightingSettings = asset` (read it with `TryGetLightingSettings`)                     |
| Camera bookmark for captures                                  | GameObject > Camera, rename `AgentView_<name>`, untick the Camera component             | `AgentCapture.SaveBookmark`                                                                         |
