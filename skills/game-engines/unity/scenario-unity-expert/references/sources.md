## 3. Cross-cluster digests used for routing and traps

Each cluster has `notes/<cluster>/_digest_docs_<cluster>.md` and `_digest_videos_<cluster>.md`. The lead uses them to route briefs and to name the traps that cut across domains:

| Cluster (owner skill)                                    | Traps the lead repeats at handoff time                                                                                                                                                      |
| -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| editor-architecture (scenario-unity-architecture)        | ScriptableObject runtime writes persist in the Editor but reset in builds (Editor tests pass falsely); awaits are not canceled on destroy or Play exit; Awaitable must not be awaited twice |
| rendering-lighting (scenario-unity-rendering-lighting)   | exposure first; a Quality level without its own URP asset silently uses the default one; URP 6.3 has no auto exposure; `SubmitRenderRequest` is the offscreen capture path                  |
| shaders (scenario-unity-shaders)                         | Render Graph only in 6.3; `_CLUSTER_LIGHT_LOOP`; `Shader.Find` shaders are stripped unless referenced; renderer feature not added = effect does nothing                                     |
| vfx (scenario-unity-vfx)                                 | VFX Graph needs compute (no WebGL); bounds too big disable culling; no GPU timings in the VFX panel on Apple Silicon                                                                        |
| performance-shipping (scenario-unity-performance)        | budgets in ms; SRP Batcher + GPU Resident Drawer with instancing checkbox and static batching off in URP 6.3; `MaterialPropertyBlock` breaks SRP Batcher and GRD compatibility              |
| mobile (scenario-unity-mobile)                           | 65% frame budget; Android keystore passwords are never stored; ANRs come from `OnApplicationPause` work                                                                                     |
| web (scenario-unity-web)                                 | ThreadPool APIs hang the browser; gzip default in 6.3; WebGPU experimental on 6.3; a stale scene list builds nothing                                                                        |
| world-3d, 2d, ui, animation-cinematics, gameplay-systems | agent-built layouts need a visual pass; Cinemachine 3 on 6.3 must be added with an explicit version; physics renames; Content Size Fitter under a Layout Group fights it                    |
