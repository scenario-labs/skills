# GUI paths (scenario-unity-performance)

Windows, menus and settings for the same procedures, for a computer-use agent or a human. Unity 6.3 names; older names in parentheses. Where a scripted path exists it is given in `procedures.md`.

## Profiling windows

| Task                             | Path                                                                                                                                                                                                                                                                                                                  | Notes                                                                                                                                                                                                        |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Profiler                         | Window > Analysis > Profiler                                                                                                                                                                                                                                                                                          | Target dropdown (Play Mode, Editor, a player by IP); Deep Profile and Call Stacks buttons on the toolbar; Highlights module (Unity 6) shows CPU Active Time vs GPU Time against Target Frame Time (dropdown) |
| Allocation call stacks           | Profiler toolbar > Call Stacks > GC.Alloc, record, select a magenta GC.Alloc sample, Details > Related Data                                                                                                                                                                                                           | use before Deep Profile (e-book p. 19-20)                                                                                                                                                                    |
| Timeline navigation              | click a frame in CPU Usage; Timeline view; A = frame all, F = frame selection; right-click marker > Show in Hierarchy; thread dropdown                                                                                                                                                                                | markers from other frames are drawn darker                                                                                                                                                                   |
| Save / load a capture            | Profiler toolbar save and load icons (`.data`); a player `.raw` loads the same way                                                                                                                                                                                                                                    | `PerfCapture.Analyze` reads both                                                                                                                                                                             |
| Profile Analyzer (package 1.4.0) | Window > Analysis > Profile Analyzer > Pull Data (or Load); Filters: Remove "FPS Wait"; Marker Summary: Top N by frame costs; right-click graph > Select Median Frame / Select Longest Frame; Compare mode with two slots; Export (CSV)                                                                               | check which file is in which slot (Hall [frame 00:25:59])                                                                                                                                                    |
| Memory Profiler (package 1.1.12) | Window > Analysis > Memory Profiler > target dropdown > Capture; Summary (Memory Usage On Device = resident), Unity Objects (Flatten Hierarchy), All Of Memory (Managed > Reserved), Compare Snapshots; open a `.snap` from `-perfSnapshot` with the import button                                                    | Memory Map view: Preferences > Analysis > Memory Profiler [verify exact path]                                                                                                                                |
| Frame Debugger                   | Window > Analysis > Frame Debugger > target > Enable; scrub events; each event says why it could not batch; GRD draws are named "Hybrid Batch Group"                                                                                                                                                                  | attach to a player: Development Build, multithreaded rendering, Run In Background on desktop; not on Web                                                                                                     |
| GRD coverage check               | Frame Debugger enabled in Play mode or on a player: search the event tree for "Hybrid Batch Group"; every other draw of a scene object is a renderer that fell out; select it, the Details panel names the GameObject and the batch-break reason (MaterialPropertyBlock, LPPV, realtime GI, non-DOTS shader, skinned) | headless: `PerfRendering.Audit` `scene.grd_eligibility` (static) and `PerfFrameDebug.Capture` (P12)                                                                                                          |
| Rendering Debugger               | Window > Analysis > Rendering Debugger (was Window > Render Pipeline > Render Pipeline Debug), or LeftCtrl+Delete on macOS in Play mode / a development player                                                                                                                                                        | Display Stats (CPU main, render, present wait, GPU per pass), Overdraw mode, GPU Resident Drawer panel                                                                                                       |
| First GPU read                   | Rendering Debugger > Display Stats: CPU Present Wait high = GPU bound; the Profiling Scopes table ranks GPU passes (post-processing, SSAO, shadows) before choosing a lever                                                                                                                                           | headless: PerfProbe `cpu_present_wait_ms` (windowed player) and wait markers                                                                                                                                 |
| Render Graph Viewer              | Window > Analysis > Render Graph Viewer                                                                                                                                                                                                                                                                               | merged passes underlined blue; 6.3 can attach to device players                                                                                                                                              |
| Game view Stats                  | Game view toolbar > Stats                                                                                                                                                                                                                                                                                             | SetPass calls, Batches, Tris; Editor-inflated                                                                                                                                                                |
| Project Auditor                  | 6.3: Package Manager > Unity Registry > Project Auditor (1.0.2), then its window; 6.4+: Window > Analysis > Project Auditor                                                                                                                                                                                           | Start Analysis; Group By Severity; right-click > Open Issue; triage by call frequency                                                                                                                        |
| Addressables duplicates          | Window > Asset Management > Addressables > Analyze (being replaced by the Addressables Build Report) [verify menu]; Memory Profiler > potential duplicates on a development build                                                                                                                                     | headless: `PerfAudit.BundleDuplicates` (P16)                                                                                                                                                                 |
| Performance Testing results      | Window > General > Test Runner, then Window > Analysis > Performance Test Report [verify menu]                                                                                                                                                                                                                        | headless: `-runTests`, sample groups in the NUnit XML output (P17)                                                                                                                                           |

## Native and GPU tools on this Mac

- Instruments (Xcode 26.6): Time Profiler, Allocations, VM Tracker on a macOS IL2CPP player; `xcrun xctrace record --template 'Time Profiler' --launch -- <player>` [not run here].
- GPU timing when GPU bound: Xcode GPU frame capture (Debug > Capture GPU Workload on an Xcode-launched player) or Instruments > Metal System Trace; the Unity Frame Debugger has no timings. RenderDoc does not support Metal (Windows or Vulkan only); on Windows: PIX, NVIDIA Nsight, RenderDoc (Game view toolbar button once RenderDoc is loaded).
