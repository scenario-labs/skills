# Critique rubric: how the VFX agent judges its own effect

Run this after every iteration, on the evidence the procedures produce (stepped captures, overdraw heatmaps, counts, profile CSV). Score each line pass / warn / fail and say which capture or number decided it. An effect is not done while a gameplay line (A) fails, whatever it looks like. Sources in brackets; [added] = this skill's own rule.

## A. Gameplay read (Jason Keyser; Nikola Damjanov)

| #   | Check                             | Evidence                                                                                                                                               | Pass when                                                                                                                                                                                       |
| --- | --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A1  | Primary shape = gameplay boundary | `VfxBudget.VisualRadius(primary layer)` / gameplay radius; capture at peak with the collider or radius drawn if needed                                 | ratio 0.85 to 1.2 [added band]; secondary layers (glow, sparks) may exceed it but read as secondary                                                                                             |
| A2  | Brightness follows importance     | `VfxTier` on every root; peak `ut_vfx.effect_energy` of each effect with the same camera and scale (`CaptureEffect`); `ut_vfx.importance_ladder(rows)` | no effect brighter than one of a higher tier; every frequent effect dimmer than every rare damaging one [Keyser]; P18: slash 0.39 < muzzle 0.46 < impact 1.50 < shockwave 2.60 < explosion 5.99 |
| A3  | Reads in context                  | `VfxStress.StressOverdraw` at the game's real spacing (`spacing`, `cam_back`) then `ut_vfx.crowd_readability(png, bg, N)`                              | at least 0.8 N separate cores and under 25% clipped white [added thresholds]; P4c: 20 explosions at 4 m read as 20 shapes, packed at 2.2 m as 6 [Keyser, Nordeus]                               |
| A4  | In and out in time                | one-shot: `life_seconds` / `end_counts`; loop: `CaptureEffect` with `stop_t` = the gameplay stop, `tail_seconds`                                       | 0 particles when the state ends; tail under `BUDGETS["mobile"]["max_tail_s"]` (0.5 s) [added]; P19: projectile gone 0.22 s after StopEmitting [Keyser]                                          |
| A5  | Value and contrast at the head    | projectile capture at mid-flight                                                                                                                       | the head is the brightest, most contrasted point; the trail falls off behind it; direction reads [added, from Nordeus "projectile textures carry direction"]                                    |
| A6  | Orientation from gameplay data    | muzzle and hit captures                                                                                                                                | muzzle along the shot, hit on the surface (up = normal), explosion not cut by the surface [Gabriel]                                                                                             |

## B. Craft (Sirhaian; Gabriel Aguiar; Hovl; Trümpler)

| #   | Check                  | Pass when                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| --- | ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| B1  | Layers, one job each   | body, heat, glow, sparks, smoke identifiable in the stepped frames; each has a reason to exist [Sirhaian, Gabriel]                                                                                                                                                                                                                                                                                                                            |
| B2  | Contrast               | dark or alpha body under additive layers; glow on top (highest sorting order); no two stacked layers share an order (flicker) [Sirhaian, Gabriel]                                                                                                                                                                                                                                                                                             |
| B3  | Never pop              | every layer fades in and out (color or alpha over life, erosion); no frame where a layer appears or vanishes at full opacity [consensus]                                                                                                                                                                                                                                                                                                      |
| B4  | Randomness             | size, rotation, frame, speed ranges on every layer; consecutive shots differ [consensus]                                                                                                                                                                                                                                                                                                                                                      |
| B5  | Motion                 | no linear curves except loops (audit `vfx.linear_curve`: Size over Lifetime, Custom Data, one-cycle Frame over Time); fast and slow elements mixed (`vfx.no_speed_contrast`, 3x [added]); a burst when a loop starts (`vfx.loop_no_start_burst`, unless a muzzle or cast plays it); something always moving (`ut_vfx.motion_gaps` on evenly spaced loop frames); sparks shrink, fire grows; drag for explosions [Nordeus, Sirhaian, Brackeys] |
| B6  | Flipbooks              | variant sheets: one random FIXED cell per particle (`VfxBudget.FlipbookCells` equal at two times, P16); animated media: frame blending (UV2 + AnimBlend when not instanced) and a decelerating curve; motion-vector flipbooks only for hero or slow elements (Nordeus), which URP particle shaders cannot do [Sirhaian, Trümpler, Fred Moreau]                                                                                                |
| B7  | Texture                | clear shape, range of values, soft edges from motion blur rather than Gaussian (crisp silhouette), nothing touching the cell border (`vfx.texture_border`); import size from the closest screen coverage (`ut_vfx.texel_verdict` on `VfxBudget.ScreenTexel`: a detailed texture magnified below 0.5 warns, a smooth glow may be magnified); channel-packed data imported linear (`vfx.data_texture_srgb`) [Nordeus, Sirhaian, Trümpler]       |
| B8  | Hard intersections     | no straight cut where billows meet geometry: soft particles on PC (depth texture), offset along the normal on mobile [added; Gabriel uses soft particles 0.5]                                                                                                                                                                                                                                                                                 |
| B9  | Lighting fit           | emissive energy unlit; smoke and dust lit or six-way when lighting changes (day and night check); URP particle shaders cast no shadow [Orson Favrel, Fred Moreau]                                                                                                                                                                                                                                                                             |
| B10 | Variation per instance | consecutive instances differ: `VfxSeed.Reseed` on spawn; per-particle values (erosion curve, random UV offset, wipe) from Custom Data, not from material copies; `CaptureEffect` with two seeds differs, with the same seed is identical (P15) [Hovl, Nordeus]                                                                                                                                                                                |
| B11 | Distortion             | drawn before the transparent it surrounds (lower order or larger Sorting Fudge, audit `vfx.distortion_order`); Opaque Texture on for tiers that keep it (`vfx.distortion_no_opaque`); P17: drawn after, 31% of the glow under it survived [Hovl; observed]                                                                                                                                                                                    |
| B12 | Ground and wall marks  | two stacked marks on the hit surface: a dark scorch, then a smaller hot core that fades first (flat quads oriented by the impact on mobile, URP decals on PC) [Gabriel Aguiar qh3]                                                                                                                                                                                                                                                            |

## F. Mistakes table (full; SKILL.md keeps the most frequent)

| Mistake                                                                      | What it looks like                                                        | Fix                                                                                                     |
| ---------------------------------------------------------------------------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| `GetComponent<T>() ?? AddComponent<T>()` on Unity objects                    | MissingComponentException: the editor's fake null defeats `??` (observed) | explicit `if (x == null)`                                                                               |
| Setting `_Surface`/`_Blend` without the inspector logic                      | opaque squares, wrong blend                                               | `BaseShaderGUI.SetMaterialKeywords(mat, null, ParticleGUI.SetMaterialKeywords)`                         |
| VFX Graph in batch Play mode with no camera target                           | 0 particles, `culled` true                                                | offscreen `targetTexture` on the camera                                                                 |
| Over-life block left on Overwrite (VFX Graph)                                | size or color curve ignores the Set value                                 | Composition Multiply                                                                                    |
| Custom event wired to Spawn Start, then `Play()`                             | nothing spawns: OnPlay is no longer bound                                 | send the custom event, or wire OnPlay too                                                               |
| Many overlapping soft quads for a constant glow                              | heatmap white at the head, no visible gain                                | one or two long-lived glow particles                                                                    |
| Flat white generated or painted shapes                                       | blocky flat blobs in motion                                               | alpha with a value range; erosion as a black point, not a hard threshold                                |
| Assigning `Camera.aspect` once                                               | freezes the aspect: later renders shift                                   | set it explicitly before every capture set                                                              |
| Shader Graph on mesh particles in 6.3                                        | CPU vertex transforms, no instancing                                      | audit `vfx.sg_no_procedural`; scenario-unity-shaders fix                                                |
| Trails module without trail material                                         | magenta ribbon                                                            | `renderer.trailMaterial`                                                                                |
| GPU instancing on a Custom Data mesh particle                                | the instanced path reads `unity_ParticleInstanceData`, not the streams    | instancing off for few particles, or a matching `UNITY_PARTICLE_INSTANCE_DATA` (scenario-unity-shaders) |
| `shader_feature_local` keyword of the uber shader toggled from gameplay code | the variant was never built: nothing changes in the player                | set keywords on the material asset (`VfxUber.Create`); swap materials at runtime                        |
| Time-scrolled shader captured on the editor clock                            | same seed, different frames (PSNR 34 dB between two runs, observed)       | `CaptureEffect` pins `_AgentVfxTime` to the simulated time (then identical)                             |
| In-memory mesh created before `EditorSceneManager.NewScene(..., Single)`     | "Mesh has been destroyed" or an invisible renderer (observed)             | create or load meshes after the new scene, or save them as assets                                       |
| A slash or ring faded by vertex alpha on a float-color mesh                  | alpha 0.25 everywhere, tint blue (observed)                               | Color32 colors (`VfxMeshes` does it)                                                                    |
| Glow flagged as "magnified"                                                  | false alarm on a soft gradient                                            | `texel_verdict` passes smooth textures (`VfxBudget.TextureDetail` under 0.005)                          |
