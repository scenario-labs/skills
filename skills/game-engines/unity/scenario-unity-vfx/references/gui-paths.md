# GUI paths: the same VFX work through windows and menus (computer-use agent or human)

Unity 6000.3 on macOS (Preferences live under **Unity > Settings**). Each row names the scripted equivalent in this skill, so a GUI agent and a script agent produce the same asset. Paths checked against the 6.3 Manual, VFX Graph 17.3 manual and the sources' on-screen frames; menu items not seen on screen in 6.3 are marked [verify].

## Particle System (Shuriken)

| Task                                | GUI path                                                                                                                                                                                                                                                            | Scripted equivalent                                                                                                                                 |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| New system                          | GameObject > Effects > Particle System                                                                                                                                                                                                                              | `VfxShuriken.Build(parent, Layer, seed)`                                                                                                            |
| One-shot burst                      | Particle System module: Looping off; Emission: Rate over Time 0, Bursts + (Time, Min, Max)                                                                                                                                                                          | `main.loop = false; emission.rateOverTime = 0; emission.SetBursts(...)`                                                                             |
| Moving emitter trail                | Emission > Rate over Distance; main > Simulation Space World                                                                                                                                                                                                        | `rateOverDistance`, `simulationSpace = World`                                                                                                       |
| Random fixed flipbook cell          | Texture Sheet Animation: Tiles X/Y; Frame over Time > Random Between Two Constants (0, tiles)                                                                                                                                                                       | `frameOverTime = new MinMaxCurve(0f, 0.999f)` (script values are normalized)                                                                        |
| Decelerating flipbook               | Texture Sheet Animation > Frame over Time > Curve (steep start, flat end)                                                                                                                                                                                           | `VfxShuriken.Decelerate()`                                                                                                                          |
| Frame blending                      | Material: Flip-Book Frame Blending; Renderer > Custom Vertex Streams: + UV2, + AnimBlend                                                                                                                                                                            | `_FlipbookBlending = 1` + `SetActiveVertexStreams(Position, Color, UV, UV2, AnimBlend)`                                                             |
| Stretch sparks                      | Renderer > Render Mode Stretched Billboard, Speed Scale 0.03 to 0.06                                                                                                                                                                                                | `renderMode = Stretch; velocityScale`                                                                                                               |
| Draw order of layers                | Renderer > Order in Layer (body 0, additive 1, sparks 1 to 2, glow top); Sorting Fudge for distortion                                                                                                                                                               | `sortingOrder`, `sortingFudge`                                                                                                                      |
| Cap screen size                     | Renderer > Max Particle Size (fraction of the screen)                                                                                                                                                                                                               | `maxParticleSize`                                                                                                                                   |
| Ribbon trail                        | Trails module: Mode Ribbon; Renderer > Trail Material (else magenta)                                                                                                                                                                                                | `trails.mode = Ribbon; renderer.trailMaterial`                                                                                                      |
| Mesh particles instanced            | Renderer > Render Mode Mesh, Enable GPU Instancing                                                                                                                                                                                                                  | `renderMode = Mesh; enableGPUInstancing = true`                                                                                                     |
| Custom data to a shader             | Custom Data module (Custom1 and Custom2: Vector, 2 components each; a curve or Random Between Two Constants per component); Renderer > Custom Vertex Streams: Position, Color, UV, Custom1.xy, Custom2.xy in that order (the list shows the TEXCOORD each lands in) | `Layer.custom1X..custom2Y` (VfxShuriken.Build) = `customData.SetMode/SetVectorComponentCount/SetVector` + `SetActiveVertexStreams(VfxUber.Streams)` |
| Mesh particle (ring, slash, scorch) | Renderer > Render Mode Mesh, Mesh = a VFX mesh, Render Alignment Local, Enable GPU Instancing off when Custom Data feeds the shader; Particle System > 3D Start Rotation for a random yaw                                                                           | `Layer.mesh`, `alignment`, `yawDeg`                                                                                                                 |
| Variation per shot                  | Particle System > Auto Random Seed on (or reseed per spawn in code); kits built with fixed seeds for captures                                                                                                                                                       | `VfxSeed.Reseed(go)`                                                                                                                                |
| Stop Action cleanup                 | Particle System module > Stop Action Destroy (root duration >= longest child)                                                                                                                                                                                       | `main.stopAction = Destroy`                                                                                                                         |
| Preview in the Scene view           | Scene view > Particle Effect overlay: Play, Restart, Stop, Playback Speed, Show Bounds                                                                                                                                                                              | `ps.Simulate(t, true, true, true)` then a capture                                                                                                   |

## Shader Graph particle instancing fix (owned by scenario-unity-shaders, listed so the VFX agent can ask for it)

Blackboard: none. Create Node > Custom Function, Type **String**, body: `#if defined(SCENEPICKINGPASS) || defined(SCENESELECTIONPASS)` / `#pragma multi_compile_instancing` / `#endif` / `#pragma instancing_options procedural:ParticleInstancingSetup` / `Out = In;`. Second Custom Function, Type **File**, pointing at an `.hlsl` that includes `Packages/com.unity.render-pipelines.universal/ShaderLibrary/ParticlesInstancing.hlsl`, function `IncludeInstancingSetup`. Wire both on the vertex position (live connection). Particle color from `unity_ParticleInstanceData[unity_InstanceID]` (Fred Moreau, Posts 2, 3). In 6.6: Graph Settings > Preprocessor Directives instead.
