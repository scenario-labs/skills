# GUI paths for the same procedures (computer-use agent or human)

Unity 6.3 on macOS (Cmd for Ctrl; Preferences are under Unity > Settings). Menus moved in 6.1 (Package Manager under Window > Package Management): check labels on the installed editor before scripting clicks. Right column: the scripted equivalent this skill ran.

| Task                                                | GUI path                                                                                                                                                                                   | Scripted equivalent (procedures.md)                                                                                                                                       |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Enter Play Mode setting                             | Edit > Project Settings > Editor > Enter Play Mode Settings > "When entering Play Mode" (Reload Domain and Scene / Reload Scene only / Reload Domain only / Do not reload Domain or Scene) | `ArchJobs.SetEnterPlayMode {"mode": ...}` (`EditorSettings.enterPlayModeOptionsEnabled`, `enterPlayModeOptions`)                                                          |
| Script execution order                              | Edit > Project Settings > Script Execution Order                                                                                                                                           | `[DefaultExecutionOrder(n)]` on the class                                                                                                                                 |
| Asset serialization, meta files                     | Edit > Project Settings > Editor > Asset Serialization > Mode = Force Text; Edit > Project Settings > Version Control > Mode = Visible Meta Files                                          | `ArchJobs.SetVcsSettings`                                                                                                                                                 |
| Smart Merge in the Editor (Perforce, UVCS)          | Edit > Project Settings > Version Control > Smart Merge (Off / Ask / Premerge)                                                                                                             | `ut_arch.git_setup_unity_merge` (Git driver), `ut_arch.yaml_merge`                                                                                                        |
| External diff and merge tool                        | Unity > Settings > External Tools > Revision Control Diff/Merge                                                                                                                            | Git config written by `git_setup_unity_merge`                                                                                                                             |
| Active Input Handling                               | Edit > Project Settings > Player > Other Settings > Active Input Handling (restart required)                                                                                               | `ArchJobs.ProjectFacts` reads `activeInputHandler`                                                                                                                        |
| Project-wide actions                                | Edit > Project Settings > Input System Package > Input Actions (button creates and assigns the default asset if missing)                                                                   | read: `EditorBuildSettings.TryGetConfigObject("com.unity.input.settings.actions", ...)`; audit: `ArchInputAudit.Audit`                                                    |
| Edit actions, maps, bindings, Listen                | Input Actions Editor (double-click the `.inputactions` asset): maps left, actions middle, "+" for bindings, Path > Listen, Interactions and Processors "+"                                 | edit the `.inputactions` JSON as text, Unity reimports (A5 step 5)                                                                                                        |
| Generate C# class from actions                      | select the `.inputactions` asset > Inspector > Generate C# Class > Apply                                                                                                                   | `.meta` `generateWrapperCode: 1` + `wrapperClassName`, then reimport (A15); each `new` is a separate asset instance, share one                                            |
| Rebinding UI sample                                 | Window > Package Management > Package Manager > Input System > Samples > Rebinding UI > Import                                                                                             | `ArchJobs.ImportSample {"package": "com.unity.inputsystem", "sample": "Rebinding UI"}`; audit with `ut_arch.rebind_audit`; rules from `RebindFlow` + `BindingStore` (A15) |
| Shortcut resolution (B vs Shift+B)                  | Edit > Project Settings > Input System Package > Complexity-Based Shortcut Resolution (Action Priority Shortcut Resolution off)                                                            | `InputSystem.settings.shortcutKeysConsumeInput = true` (default false in 1.20, observed)                                                                                  |
| Input Debugger (live devices, actions)              | Window > Analysis > Input Debugger                                                                                                                                                         | `InputTestFixture` virtual devices in tests                                                                                                                               |
| PlayerInput behavior and events                     | select the object > Inspector > PlayerInput > Behavior (Send Messages / Broadcast Messages / Invoke Unity Events / Invoke C Sharp Events) > Events foldout                                 | `PlayerInput.Instantiate(prefab, controlScheme:, pairWithDevice:)`, `notificationBehavior = InvokeCSharpEvents`                                                           |
| Create a ScriptableObject asset                     | Project window > right-click > Create > Game > Item Definition (from `[CreateAssetMenu]`)                                                                                                  | `ArchJobs.CreateAssets {"specs": ...}`                                                                                                                                    |
| Wire a reference in the Inspector                   | drag the asset into the slot                                                                                                                                                               | `SerializedObject.FindProperty(name).objectReferenceValue = asset; ApplyModifiedPropertiesWithoutUndo()`                                                                  |
| Raise an event channel by hand (debug plan)         | select the channel asset in Play mode > Inspector > Debug > "Raise (debug value)" (`EventChannelEditor`); tick "Log Raises" to log each raise                                              | `ArchPlayMode.PlayProbe {"invoke": [{"path": "<channel>.asset", "method": "RaiseDebug"}]}` (A11), or `ut_live` calling `RaiseDebug()` in a running editor                 |
| Wire a UnityEvent response                          | Inspector > UnityEvent "+" > drag the target > pick the method                                                                                                                             | `UnityEventTools.AddVoidPersistentListener(evt, target.Method)`; Edit-mode calls need `SetPersistentListenerState(i, EditorAndRuntime)`                                   |
| Script execution order of the composition root      | Edit > Project Settings > Script Execution Order > "+" > GameRoot, negative value                                                                                                          | `[DefaultExecutionOrder(-1000)]` on the class (A14)                                                                                                                       |
| Polymorphic `[SerializeReference]` list             | Inspector support for choosing the concrete type depends on the editor and custom drawers [not verified here]                                                                              | `ArchJobs.CreateAssets` `"managed_refs"` (`SerializedProperty.managedReferenceValue`)                                                                                     |
| Development build                                   | File > Build Profiles > (platform) > Development Build                                                                                                                                     | `ut_run.build(P, "macos", development=True)` (A12)                                                                                                                        |
| Assembly definition                                 | Project window > right-click > Create > Scripting > Assembly Definition; Inspector: References, Auto Referenced, No Engine References, Define Constraints                                  | `.asmdef` JSON written by `ut_arch.scaffold`; check with `ArchJobs.AssemblyGraph`                                                                                         |
| Test Runner                                         | Window > General > Test Runner (EditMode / PlayMode tabs, Run All)                                                                                                                         | `ut_run.run_tests(P, "EditMode", assemblies="Game.Tests.EditMode")`                                                                                                       |
| Prefab Mode in isolation (root Transform editable)  | double-click the prefab asset; in context: select an instance > P                                                                                                                          | `PrefabUtility.LoadPrefabContents` / `SaveAsPrefabAsset` / `UnloadPrefabContents`                                                                                         |
| Instance overrides                                  | select the instance > Inspector > Overrides > Apply All / Revert All                                                                                                                       | `PrefabUtility.ApplyPrefabInstance(root, InteractionMode.AutomatedAction)`                                                                                                |
| Serialized property names                           | Inspector kebab menu > Debug, Option-hover a label                                                                                                                                         | `SerializedObject.GetIterator()` + `NextVisible` (as `ArchJobs.InspectAsset` does)                                                                                        |
| Swap a component for a derived class keeping values | Inspector in Debug mode > Script field                                                                                                                                                     | `SerializedObject.FindProperty("m_Script").objectReferenceValue = monoScript` [not run here]                                                                              |
| Crash in Play mode                                  | before reopening Unity, copy `Temp/__Backupscenes/*.backup` out and rename to `.unity` (Game Dev Guide, mCKeSNdO_S0 [00:03:31])                                                            | same, by shell [not run here]                                                                                                                                             |
| Script templates per project                        | put templates in `Assets/ScriptTemplates/` named like `1-Scripting__MonoBehaviour Script-NewMonoBehaviourScript.cs.txt` (6000.3 naming, verified on disk by the docs distiller)            | file copy [not run here]                                                                                                                                                  |
