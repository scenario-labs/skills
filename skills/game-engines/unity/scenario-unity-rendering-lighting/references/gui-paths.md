# GUI paths (computer-use agent or human) for the same procedures

Menu names follow the 6.3 Manual and the notes' frames (Unity 6.0 to 6.3). The live tests ran headless, so no window below was clicked on this Mac: verify a label on first use. Each row names the code path that does the same thing.

## Pipeline and tiers (procedure P1, P2)

| Task                                                                          | GUI path                                                                                                                                                                                                                                                                            | Code path                                                                                                                                          |
| ----------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Which asset renders                                                           | Edit > Project Settings > Quality: select the level, "Render Pipeline Asset" field (None = Graphics default); the level matrix sets per-platform defaults                                                                                                                           | `LightingPipeline.ReportPipeline`                                                                                                                  |
| Graphics default asset                                                        | Edit > Project Settings > Graphics > Default Render Pipeline                                                                                                                                                                                                                        | `graphics_default` arg of `ConfigureTiers`                                                                                                         |
| Hidden URP asset fields                                                       | select the URP asset > Inspector > More (⋮) > Show All Advanced Properties (SRP Batcher, Dynamic Batching, Store Actions, Mixed Lighting, Use Rendering Layers, Light Cookies, SH Evaluation Mode, Conservative Enclosing Sphere)                                                   | `asset_props` with `m_` names                                                                                                                      |
| Renderer (path, depth priming, depth texture mode, post)                      | URP asset > Rendering > Renderer List > double-click the renderer                                                                                                                                                                                                                   | `renderer_props` (`renderingMode`, `depthPrimingMode`, `copyDepthMode`)                                                                            |
| Shadows                                                                       | URP asset > Shadows (Max Distance, Working Unit, Cascade Count and splits, Last Border, biases, Soft Shadows + Quality)                                                                                                                                                             | `m_ShadowDistance`, `m_ShadowCascadeCount`, `m_Cascade2Split`, `m_CascadeBorder`, `m_SoftShadowsSupported`, `m_SoftShadowQuality`                  |
| Additional light shadows                                                      | URP asset > Lighting > Additional Lights (Per Pixel) > Cast Shadows, Shadow Atlas Resolution, Shadow Resolution Tiers; per light: Light > Shadows > Resolution tier                                                                                                                 | `m_AdditionalLightShadowsSupported`, `m_AdditionalLightsShadowmapResolution`, tiers                                                                |
| Light Probe System                                                            | URP asset > Lighting > Light Probe System (Light Probe Groups / Adaptive Probe Volumes), Memory Budget, SH Bands, streaming, Lighting Scenarios                                                                                                                                     | `m_LightProbeSystem` (or `LightingBake.SetProbeSystem`)                                                                                            |
| AA and upscaling                                                              | URP asset > Quality (HDR, HDR Precision, Anti Aliasing (MSAA), Render Scale, Upscaling Filter incl. Spatial-Temporal Post-Processing); Camera > Rendering > Anti-aliasing (FXAA, SMAA, TAA)                                                                                         | `m_MSAA`, `m_RenderScale`, `m_UpscalingFilter`; camera `GetUniversalAdditionalCameraData().antialiasing`                                           |
| Shadowmask mode per level                                                     | Project Settings > Quality > (level) > Shadows > Shadowmask Mode (Shadowmask / Distance Shadowmask)                                                                                                                                                                                 | `quality_props: {"shadowmaskMode": 0 or 1}` in `ConfigureTiers`                                                                                    |
| Grading mode and LUT size                                                     | URP asset > Post-processing > Grading Mode, LUT Size (one mode and size on every tier)                                                                                                                                                                                              | `m_ColorGradingMode`, `m_ColorGradingLutSize`; ReportPipeline `tiers.grading_mode_mismatch`                                                        |
| Per-tier post profile (P2c)                                                   | URP asset > Volumes > Volume Profile (each tier's asset its own; the template's two share SampleSceneProfile)                                                                                                                                                                       | `ConfigureTiers` `volume_profile` + `volume_overrides`                                                                                             |
| Renderer features per tier                                                    | Renderer asset > Renderer Features > Screen Space Ambient Occlusion (Downsample, After Opaque, Quality)                                                                                                                                                                             | `renderer_features` {"ScreenSpaceAmbientOcclusion": {"m_Settings.Downsample": true}}                                                               |
| Static batching (GRD)                                                         | Project Settings > Player > Other Settings > Static Batching (per platform)                                                                                                                                                                                                         | `graphics.static_batching`                                                                                                                         |
| GPU Resident Drawer (P2b; deep profiling owned by scenario-unity-performance) | Project Settings > Graphics > Shader Stripping > BatchRendererGroup Variants = Keep All; URP asset > Rendering > GPU Resident Drawer = Instanced Drawing; renderer Forward+; Player > Other Settings > Static Batching off; verify "Hybrid Batch Group" draws in the Frame Debugger | `m_GPUResidentDrawerMode` + `graphics.brg_stripping` (`m_BrgStripping` on GraphicsSettings through SerializedObject; the C# property is read-only) |

## Scenes, lights, exposure (P3, P4)

| Task                       | GUI path                                                                                                                                                                      | Code path                                                              |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| Sun and environment        | Window > Rendering > Lighting > Environment tab: Skybox Material, Sun Source, Environment Lighting Source (Skybox, Gradient, Color) and Intensity Multiplier                  | `LightingScenes.SetLights` (`sun`, `ambient`)                          |
| Lights                     | Light Inspector: Mode (Realtime, Mixed, Baked), Intensity, Temperature, Indirect Multiplier, Shadow Type, Strength; Window > Rendering > Light Explorer to sort and bulk-edit | `SetLights`; audit lists all lights                                    |
| Exposure (URP: Fixed only) | Volume > Add Override > Post-processing > Color Adjustments > Post Exposure                                                                                                   | `LightingPost.SetupVolume` `{"ColorAdjustments": {"postExposure": x}}` |
| Zone exposure              | GameObject > Volume > Box Volume; Priority 1, Blend Distance; the Box Collider bounds the zone                                                                                | `SetupVolume` with `global: false`, `box`                              |

## Baking and probes (P5 to P7)

| Task                      | GUI path                                                                                                                                                                                                                                                                                        | Code path                                                                                                                                                                                |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Lighting Settings asset   | Window > Rendering > Lighting > Scene tab > New Lighting Settings (or assign one)                                                                                                                                                                                                               | `LightingBake.Bake` (`lighting_settings`)                                                                                                                                                |
| Bake settings             | same tab > Lightmapping Settings: Lightmapper (Progressive GPU; CPU unsupported on Apple Silicon), samples, bounces, Filtering (Advanced: denoisers, Gaussian or A-Trous), Lightmap Resolution, Padding, Max Lightmap Size, Compression, Directional Mode; Mixed Lighting > Lighting Mode       | `preset` + `settings`                                                                                                                                                                    |
| Bake                      | Lighting window > Generate Lighting (dropdown: bake probes only)                                                                                                                                                                                                                                | `Lightmapping.Bake()` in `Bake`                                                                                                                                                          |
| Static and GI flags       | Inspector > Static dropdown > Contribute GI, Reflection Probe Static; Mesh Renderer > Lighting: Receive Global Illumination (Lightmaps or Light Probes), Scale In Lightmap, Stitch Seams                                                                                                        | done by `Bake` (`dynamic`, `probe_lit`, `small_size`, `lightmap_scale`)                                                                                                                  |
| Lightmap UVs              | select the model > Model tab > Generate Lightmap UVs, Margin Method Calculate (Min Lightmap Resolution, Min Object Scale)                                                                                                                                                                       | `ModelImporter.generateSecondaryUV` (scenario-unity-pipeline-automation import rules)                                                                                                    |
| APV                       | GameObject > Light > Adaptive Probe Volume (Mode Global, or Local with size handles and Fit to Scene); Lighting window > Adaptive Probe Volumes tab (Min/Max Probe Spacing, Sky Occlusion, Rendering Layer Masks, Lighting Scenarios, Probe Positions Don't Recalculate)                        | `Bake` with `gi: "apv"` or `apv: true` (Global volume; spacing and masks: GUI or `ProbeVolumeBakingSet` fields [verify])                                                                 |
| APV leak options          | Volume > Add Override > Lighting > Adaptive Probe Volumes Options (Normal Bias, View Bias, Leak Reduction Mode, Sampling Noise); per tier on the URP asset's profile (Performance on phones, Quality on PC)                                                                                     | `SetupVolume` or `ConfigureTiers volume_overrides` `{"ProbeVolumesOptions": {"leakReductionMode": "Performance"}}` (enum None, Performance, Quality; ValidityBased is an obsolete alias) |
| APV Rendering Layer Masks | URP asset > Lighting > (More) > Use Rendering Layers; Lighting window > Adaptive Probe Volumes > Rendering Layer Masks (up to 4, names and layers); Mesh Renderer > Additional Settings > Rendering Layer Mask; Rendering Debugger > Probe Volumes > Probe Shading Mode = Rendering Layer Masks | `Bake` `apv_layers` (baking set `useRenderingLayers` / `renderingLayerMasks` through SerializedObject)                                                                                   |
| Shadowmask channel budget | Scene view > Draw Mode > Light Overlap (texels where more than 4 Mixed lights overlap)                                                                                                                                                                                                          | audit `light.shadowmask_overlap`                                                                                                                                                         |
| Lighting Mode per tier    | Project Settings > Quality > (level) > Shadows > Shadowmask Mode; Lighting window > Mixed Lighting > Lighting Mode                                                                                                                                                                              | P13 shadowmask range scene + `shadow_contrast`                                                                                                                                           |
| Probe Adjustment Volume   | APV Inspector > Add Component > Light > Probe Adjustment Volume, Mode Invalidate Probes                                                                                                                                                                                                         | component `ProbeAdjustmentVolume` (fields listed in procedures, P7; not run)                                                                                                             |
| Rendering Layers          | Project Settings > Tags and Layers > Rendering Layers; Light > Rendering Layers; Mesh Renderer > Additional Settings > Rendering Layer Mask                                                                                                                                                     | `Renderer.renderingLayerMask`, `Light.renderingLayerMask`                                                                                                                                |
| Reflection probes         | GameObject > Light > Reflection Probe; Type Baked, Box Projection, Importance, Blend Distance, Box Size; Bake button                                                                                                                                                                            | `Bake` `reflection_probes`                                                                                                                                                               |

## Post and debugging (P8, P9)

| Task                           | GUI path                                                                                                                                                                                                                                           | Code path                                                                                                          |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Volumes                        | GameObject > Volume > Global Volume; Volume > Profile > New; Add Override                                                                                                                                                                          | `SetupVolume`                                                                                                      |
| Project default profile        | Project Settings > Graphics > URP > Volume Profiles (bottom of the Unity 6 stack); URP asset > Volumes > Volume Profile                                                                                                                            | `LightingPost.GraphicsDefaultProfile()` reads it                                                                   |
| Camera post flag               | Camera > Rendering > Post Processing                                                                                                                                                                                                               | `renderPostProcessing` (set by `SetupVolume`)                                                                      |
| Renderer post                  | Renderer > Post-processing > Enabled (off also removes tonemapping)                                                                                                                                                                                | `ReportPipeline` flag `urp.post_off_with_hdr`                                                                      |
| Scene view debug               | Scene view > Draw Mode: Baked Lightmap, UV Charts, UV Overlap, Contributors / Receivers, Texel Validity, Light Overlap, Shadow Cascades                                                                                                            | no batch equivalent (no Scene view headless); audits and captures instead                                          |
| Rendering Debugger             | Window > Analysis > Rendering Debugger (Ctrl+Backspace in a player): Probe Volumes (Display Probes, Bricks, Debug Probe Sampling), Lighting debug modes, Material overrides (mirror audit), STP debug views, GPU Resident Drawer occlusion overlay | captures + chrome ball + gray cards (no scripted access to per-pixel probe sampling)                               |
| Render Graph Viewer            | Window > Analysis > Render Graph Viewer (blue line = merged native pass, red write, green read; 6.3: pick a connected device player in the connection dropdown)                                                                                    | `LightingCapture.PassAudit` + `L.pass_summary` (native passes read by reflection), GPU A/B in a development player |
| Bloom filter                   | Volume > Bloom > Filter (Gaussian, Dual, Kawase: 6.3), High Quality Filtering, Downscale, Max Iterations                                                                                                                                           | `{"Bloom": {"filter": "Kawase"}}` on the tier profile                                                              |
| PSO warm-up                    | no window: GraphicsStateCollection is code only; Project Settings > Graphics > Shader Build Settings and each Build Profile's Shader Build Settings for keyword dynamic branches                                                                   | `Runtime/AgentPSOWarmup.cs` + `L.pso_run` (P15)                                                                    |
| Frame Debugger                 | Window > Analysis > Frame Debugger                                                                                                                                                                                                                 | `AgentProfile` counters (draw calls, SetPass, batches)                                                             |
| GI cache                       | Unity > Settings (Preferences) > GI Cache > Clean Cache                                                                                                                                                                                            | not scripted (deletes baked data)                                                                                  |
| Lightmap encoding per platform | Project Settings > Player > Other Settings > Lightmap Encoding; HDR Cubemap Encoding                                                                                                                                                               | per-texture lightmap overrides are wiped by every rebake                                                           |
