# GUI paths: networking and security

Menus and panels for the same procedures, for a human or a computer-use agent. Paths are from the
Creator Docs (October 2026) unless marked [added]. The scripted substitute is named for each; prefer
it when an agent drives Studio through the toolkit.

| Task                                                | GUI path                                                                                                                                          | Scripted substitute                                                                                                                                                                                                   |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Server Authority on                                 | Explorer, select Workspace, Properties: `AuthorityMode` = Server (sets the five companion settings)                                               | Rojo `$properties` on Workspace ([procedures.md](procedures.md) P11); scripts cannot read or set it from the Studio MCP context, and `inspect_instance` shows no Workspace properties: check by behavior (P11)        |
| Server Authority visualizer                         | During a playtest, Ctrl+Shift+F6 (Cmd+Shift+F6 on Mac)                                                                                            | None; log `RunService:GetPredictionStatus` and server heartbeat yourself                                                                                                                                              |
| Network Simulator (beta)                            | File, Beta Features, enable New Device Simulator, restart; then Test, Device Simulator, the Network pill above the viewport; pick a preset, Apply | `rbx_net.set_latency(studio, inbound_ms, outbound_ms, jitter_ms, loss_pct)` before Play (NetworkSettings properties)                                                                                                  |
| Network emulation settings                          | Studio Settings, Network tab (same values as the simulator)                                                                                       | Same NetworkSettings properties                                                                                                                                                                                       |
| Network owner outlines                              | During a playtest, the visualization options button at the upper right of the viewport, toggle Network owners                                     | Server: `part:GetNetworkOwner()` per part                                                                                                                                                                             |
| Ownership region (older Studio builds)              | Studio Settings, Physics, Are Regions Shown [added, from a 2021 video; may be replaced by the option above]                                       | Same as above                                                                                                                                                                                                         |
| Developer Console (server and client logs, network) | F9 during a playtest or a live session                                                                                                            | `get_console_output` through the toolkit (`Playtest.console()`)                                                                                                                                                       |
| Performance Stats (ping, sent and received)         | Ctrl+Alt+F7 (Cmd+Option+F7)                                                                                                                       | Client `Stats.DataSendKbps`, `Stats.DataReceiveKbps`; server `player:GetNetworkPing()`                                                                                                                                |
| Multi-client test                                   | Test, Clients and Servers, choose the number of players, Start                                                                                    | `StudioTestService:ExecuteMultiplayerTestAsync(numPlayers, args)` (plugin security, 1 to 8 clients, returns the value the server passes to `EndTest`; API reference). Not run here: each client opens a Studio window |
| Ban management                                      | Creator Hub, the experience, Moderation [added, verify in the dashboard]                                                                          | `Players:BanAsync`, `Players:UnbanAsync`, `Players:GetBanHistoryAsync`                                                                                                                                                |
| Remote and script search                            | View, Find All (Ctrl+Shift+F) for `OnServerEvent`, `OnServerInvoke`, `Triggered`, `MouseClick` [added]                                            | `rbx_net.audit_place` (offline) or `NetAudit.run(game, Audit)` in Edit                                                                                                                                                |
