# GUI paths: performance and release

Menus, panels and keys for the same procedures, for a human or a computer-use agent. Paths are from
the Creator Docs (October 2026) unless marked otherwise. Mac keys are in parentheses. The scripted
substitute is named for each row; prefer it when an agent drives Studio through the toolkit.
Procedure ids point to [procedures.md](procedures.md).

## Publishing and release (a person does these)

| Task                            | GUI path                                                                                                                                                                                             | Notes                                                                                                      |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Publish a place                 | File > Publish (first time: icon, thumbnail, name, genre, description)                                                                                                                               | Publishing stores a new version; release to the public is a separate step                                  |
| Change the start place          | Creator Dashboard > the game > Configurations > Places > Edit in Studio on the new place; File > Publish As, same game, current start place, Overwrite                                               | Never Publish here: it publishes the place over itself. Restart servers if live                            |
| Restart servers after an update | Creator Dashboard > Creations > the game > Configurations > Server management, select places, Restart Servers; tick "Restart only servers with outdated versions"; optional delay of 1 to 60 minutes | Restart when the saved data format changed; otherwise old servers drain. Restart does not block reconnects |
| Roll back a bad update          | Creator Dashboard > Creations > the game > Configurations > Places > the place > Version History > Restore; or Studio Window > Version History > Open Local Copy, then File > Save to Roblox As      | Restoring creates a new version and does not publish it: open, publish, then restart servers               |
| Release and audience            | File > Publish > Continue > Content Maturity questionnaire; Creator Dashboard > Publish settings > Manage Audience                                                                                   | Fees and limits are in [expert-notes.md](expert-notes.md); never pay or release without the owner          |
| Early testers                   | File > Invite early testers (up to 10)                                                                                                                                                               | Watermarked preview before release                                                                         |

Publishing automation (Open Cloud place publishing, restart endpoints) belongs to
scenario-roblox-tooling. This skill never publishes.
