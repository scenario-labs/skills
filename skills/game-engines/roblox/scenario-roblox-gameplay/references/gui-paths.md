# GUI paths: gameplay systems

Menus and panels for the same procedures, for a human or a computer-use agent. Paths are from the
Creator Docs (October 2026) unless marked [added]. Prefer the scripted substitute when an agent
drives Studio through the toolkit.

| Task                                      | GUI path                                                                                                              | Scripted substitute                                                                                                                                                                                                                                                          |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Insert a constraint                       | Model tab, click and hold the corner arrow of a constraint button, pick the type, then click two parts or attachments | `Instance.new("CylindricalConstraint")` and set `Attachment0`, `Attachment1` ([procedures.md](procedures.md) P9)                                                                                                                                                             |
| See constraint axes                       | View menu, Show Constraint Details (Alt+D or Option+D); Show Welds (Alt+W)                                            | Read `Attachment.WorldCFrame` axes in code; capture with the details on                                                                                                                                                                                                      |
| See mechanisms                            | Visualization Options (upper right of the viewport), Mechanisms                                                       | `part.AssemblyRootPart`, `part:GetConnectedParts(true)`                                                                                                                                                                                                                      |
| Network owner outlines                    | During a playtest: Visualization Options, Network owners                                                              | Server: `part:GetNetworkOwner()` (P5, P9)                                                                                                                                                                                                                                    |
| Navigation mesh, modifier and link labels | Visualization Options (upper right of the viewport), Navigation mesh, Pathfinding modifiers, Pathfinding links        | `Path:GetWaypoints()` and waypoint `Label` in code, drawn with `DebugDraw` (P13); capture with the mesh on                                                                                                                                                                   |
| Collision groups                          | Window menu, 3D, Collision Groups; Add Group, then the grid                                                           | `workspace:RegisterCollisionGroup`, `workspace:CollisionGroupSetCollidable`, `BasePart.CollisionGroup`                                                                                                                                                                       |
| Tags                                      | Select the instance, Properties window, Tags section, +                                                               | `CollectionService:AddTag(inst, "Car")`                                                                                                                                                                                                                                      |
| Input actions                             | Window menu, Input, Input Action Manager (writes to ReplicatedStorage.Inputs)                                         | Create `InputContext`, `InputAction`, `InputBinding` instances (P7)                                                                                                                                                                                                          |
| Touch button for an action                | Build a button under StarterGui, then select the action's touch binding, Properties, UIButton, pick the button        | `GameplayInputs.build` sets `InputBinding.UIButton` (P7)                                                                                                                                                                                                                     |
| Draw waypoints and query boxes            | None (Studio draws only engine state)                                                                                 | `DebugDraw.path`, `DebugDraw.box` adornments (P13)                                                                                                                                                                                                                           |
| VehicleSeat tuning                        | Select the seat, Properties: MaxSpeed, Torque, TurnSpeed, HeadsUpDisplay                                              | Set the same properties in code (P9)                                                                                                                                                                                                                                         |
| Fixed simulation and Server Authority     | Explorer, select Workspace, Properties: `AuthorityMode`, `UseFixedSimulation`                                         | Rojo `$properties` on Workspace (scenario-roblox-networking); not readable from the Studio MCP context (P11)                                                                                                                                                                 |
| Server Authority visualizer               | During a playtest, Ctrl+Shift+F6 (Cmd+Shift+F6 on Mac)                                                                | None for the panel; log server heartbeat with the AgentKit `Stats`                                                                                                                                                                                                           |
| Server cost while testing                 | Developer Console (F9), or View, MicroProfiler [added]                                                                | AgentKit `Stats.frames` and `Stats.snapshot` in the Server data model (P5); profiling belongs to scenario-roblox-performance                                                                                                                                                 |
| Walk a character to a point               | Playtest, then WASD                                                                                                   | `character_navigation` through `Playtest.walk_to` (P6)                                                                                                                                                                                                                       |
| Multi-client test                         | Test, Clients and Servers, choose the number of players, Start                                                        | `StudioTestService:ExecuteMultiplayerTestAsync(numPlayers, args)` from a plugin script (plugin security, 1 to 8 clients, returns the value the server passes to `EndTest`); not run here because each client opens a Studio window, so two-player combat stays "not yet run" |
| Build an R15 rig for an NPC               | Avatar tab, Rig Builder [added, from the 2025 videos]                                                                 | `Players:CreateHumanoidModelFromDescriptionAsync(Instance.new("HumanoidDescription"), Enum.HumanoidRigType.R15)` (P1)                                                                                                                                                        |
