# Jobs

Each picture gets one job, written in capitals in its line. The example lines are quoted from the eight kept sets in [kept-prompts.md](kept-prompts.md); those prompts name the main subject WHO (once STAR) and the place WHERE (once STAGE).

| Job                      | Lends                            | Example picture        | Example line                                                                                                                                       |
| ------------------------ | -------------------------------- | ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| WHO                      | the subject                      | crayon monster drawing | "Image 1 (child's crayon drawing) = WHO. Turn this crayon monster into a soft, plush 3D animated character … Keep its lopsided, hand-drawn charm." |
| WHO, idea only           | only the concept of the subject  | gecko photo            | "Image 1 (gecko) = STAR. Use only the idea of a gecko … Do not copy the photo's pose, lighting, colors or realism."                                |
| WHERE                    | the place                        | 1970s kitchen          | "Image 3 (1970s kitchen) = WHERE. This kitchen layout and colors … all made of clay."                                                              |
| STYLE                    | medium, render, texture          | clay snail             | "Image 4 (clay snail) = STYLE. This is the most important job … Do not include the snail."                                                         |
| LIGHT                    | light only                       | sun through blinds     | "Image 4 (sun through blinds) = LIGHT only. Hard midday sun through venetian blinds throws crisp diagonal stripes …"                               |
| PALETTE                  | the allowed colors               | ink swatch             | "Image 5 (color swatch) = PALETTE, strictly. The whole print uses only these inks … No green anywhere."                                            |

## Choosing a job for a picture

- A photo that should only inspire, not appear, is WHO with "Use only the idea of", or WEAR with "designed from this", followed by a "Do not show a real ..." clause.
- A face whose mood should move onto a non-human subject is EXPRESSION, never WHO: list the anatomy that must not come along.
- A color swatch is PALETTE "strictly", with each element's color named in the line; a swatch alone recolors weakly.
- Variants were explored on one set by changing one picture's job (WHO to PATTERN, for example). A picture left without a job in such a variant gets its own line: "Image 4 = no job: ignore it completely."
