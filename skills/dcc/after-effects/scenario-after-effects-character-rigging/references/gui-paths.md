# GUI paths

For a person or a computer-use agent. Shortcuts: Windows first, macOS after the slash.

| Stage                          | Path or tool                                                                                                                                                     |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| import layered art             | File > Import > File, Import As: Composition - Retain Layer Sizes                                                                                                |
| move an anchor onto a joint    | Pan Behind (Anchor Point) tool, Y; read the joint position in the Info panel                                                                                     |
| parent                         | Parent & Link column pick whip, or Shift-drag the pick whip to snap the child to the parent                                                                      |
| controller null                | Layer > New > Null Object, Ctrl+Alt+Shift+Y / Cmd+Option+Shift+Y                                                                                                 |
| expression controls            | Effect > Expression Controls > Slider Control, Checkbox Control, Point Control                                                                                   |
| add an expression              | Alt / Option click the stopwatch                                                                                                                                 |
| hold key                       | Ctrl+Alt click / Cmd+Option click a key toggles hold                                                                                                             |
| retime keys keeping eases      | select keys, Alt / Option drag the outer key (Ben Marriott 00:09:45)                                                                                             |
| separate dimensions            | right-click Position > Separate Dimensions                                                                                                                       |
| time remap                     | Layer > Time > Enable Time Remapping, Ctrl+Alt+T / Cmd+Option+T                                                                                                  |
| markers on contacts            | numpad * on the layer (School of Motion walk)                                                                                                                    |
| Puppet pins                    | Puppet Position Pin tool, Ctrl+P / Cmd+P, click on the layer in the Comp or Layer panel; Overlap, Starch, Advanced and Bend pin tools in the same tool group     |
| record pin motion              | hold Ctrl / Cmd and drag a pin; Record Options: Speed, Smoothing, Use Draft Deformation                                                                          |
| Puppet engine and Density      | Effect Controls > Puppet > Puppet Engine (Advanced default), Mesh > Density                                                                                      |
| Convert Audio to Keyframes     | select the audio layer, Animation > Keyframe Assistant > Convert Audio to Keyframes                                                                              |
| on twos                        | Effect > Time > Posterize Time, Frame Rate 12, on an adjustment layer                                                                                            |
| boil                           | Effect > Distort > Turbulent Displace on an adjustment layer, seed expression                                                                                    |
| Liquify head turn              | Effect > Distort > Liquify, brushes in Effect Controls                                                                                                           |
| Duik Angela                    | Window > Duik Angela.jsx (ScriptUI panel): Bones, Link Art, Auto-rig, Animation > Walk / Run Cycle                                                               |
| Rubberhose 3                   | Window > Extensions > Rubberhose 3                                                                                                                               |
| Graph Editor scale of a motion | select keys, Graph Editor transform box, Ctrl / Cmd drag a handle (School of Motion walk)                                                                        |
| Outline view check of joints   | in Illustrator, View > Outline, Ctrl+Y / Cmd+Y (Jake Bartlett 00:17:27)                                                                                          |
| joint markers layer            | in Illustrator, Outline view, copy one of each joint circle, Paste in Place Ctrl+Shift+V / Cmd+Shift+V on a new top layer, bright color (Jake Bartlett 00:24:47) |
| zero nulls                     | Duik: Links and Constraints > Add Zero; native: a null at the controller's position, controller parented to it (Jake Bartlett, Y0RRBVnn2MA 00:29:38)             |
| lock and shy                   | Timeline lock and shy switches on art and bones; Hide Shy Layers button at the top of the Timeline (Y0RRBVnn2MA 00:30:43)                                        |
