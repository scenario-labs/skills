# GUI paths: menus, hotkeys and tool settings (Maya 2027, for a computer-use agent)

Load when operating Maya's interface instead of, or next to, the scripted procedures (weight painting, Shape Editor sculpting, Pose Editor, ML Deformer training). Menu names come from the Maya 2027 Help and the 2027 Skin Tools quick start video; items marked [verify] come from older tutorials. macOS: Ctrl in the Help means Control, Alt means Option (version deltas). Menu set for everything below: Rigging (F3), unless stated. P numbers point to `procedures.md`.

## Skin Tools window (P4, P5, P6, P7)

Open: Skin > Skin Tools (then **Initialize Skin Layers**), or Skin > Initialize Skin Layers. After initialization Skin > Paint Skin Weights opens Skin Tools. Preference: Preferences > Animation > Rigging > Paint Skin Weights Tool (Classic by default).

| Area                        | Use                                                                                                                                                                                                                                                         |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Skin menu (window menu bar) | pick the active skinCluster when a mesh has several (checkmark; newest first)                                                                                                                                                                               |
| Layers list                 | right-click > Create Layer (or Layers > Create Layer); double-click to rename; toggle a layer to find the culprit (Makauskas [00:13:54]); reorder: what shows through a mask is what lies below (Jao [00:26:44]); layer groups share one mask (hands, feet) |
| Influences list             | search field; **Mask** is listed first: select it to paint the layer alpha; Tools > Add Influences isolates joints to the layer                                                                                                                             |
| Tools menu                  | Assign From Closest Joint (block), Add Influences, Prune Small Skin Weights (active layer only)                                                                                                                                                             |
| Paint tab                   | brush modes Replace, Add, Scale, Smooth, Sharpen; projection Surface, Volume (across shells), Screen (through the mesh); shape Hard, Soft, Gaussian; Intensity; Display > Current influence, colored; **Interactive Mirror**                                |
| Set Weights tab             | Common Settings > Mirror; Smooth > Apply on a selection (grow with Shift + >, repeat, Maya LC [00:02:48]); influence limit visible while painting                                                                                                           |
| Mirror tab                  | axis, Mirror (one-time copy), Influence Mapping editor, Vertex Mapping (symmetry mesh)                                                                                                                                                                      |
| Effects tab                 | Mirror effect (applied on write, not visible while painting), Prune Small Weights before writing, Max Influences (post-process)                                                                                                                             |
| Joints panel                | right-click: Lock Selected, Unlock Selected, Lock Unselected, Unlock Unselected                                                                                                                                                                             |
| Hotkeys in the paint tool   | H on-screen help; B + left-drag brush radius; hold Shift to smooth while painting; Ctrl+Z undo; S sample the influence under the cursor (ngSkinTools2, Makauskas [00:01:55]) [verify]                                                                       |
| Export and import layers    | Skin Tools export/import of layered data (Help names Export and Import; Jao used Export Layers to JSON and Import Layers with vertex ID transfer) [verify menu location]                                                                                    |
| Finish                      | Skin > Delete Skin Layers (weights kept); Skin > Reset Default Weights deletes layers and re-initializes                                                                                                                                                    |

Expert order in this window: create a region layer, add its influences, Assign From Closest Joint, Replace intensity 1 to block, pose with the calisthenics animation, Smooth strongly while scrubbing, select Mask, Replace-flood the region, polish the mask with Smooth (Makauskas, Jao, quick start).
