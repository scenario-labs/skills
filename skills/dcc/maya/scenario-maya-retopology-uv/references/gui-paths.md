# GUI paths: menus, hotkeys, marking menus and tool settings

For a computer-use agent (or a human) doing the same procedures in the Maya 2027 interface. Modeling menu set unless stated. macOS: Ctrl is Control and Alt is Option, not Command (Maya 2027 Help, Fundamentals). Hotkeys come from the Maya 2018 panel on screen in FlippedNormals 9N4rG5qHWgk (frame f_01125) and from the 2027 docs' prose; the 2027 Quad Draw hotkey table was lost from the saved pages, so check the tool panel before relying on a key [verify].

## Retopology

| Task                          | Path                                                                                                                           | Notes                                                                                                                                                                                                                                                  |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Set the reference (live) mesh | select it, Status Line Make Live icon; or right-click > Make Live; or Modify > Make Live                                       | several live objects allowed; middle-click the icon toggles the last live surface; without one Quad Draw snaps to the grid                                                                                                                             |
| X-ray the reference           | Modeling Toolkit > Object > X-Ray                                                                                              | helps see the new mesh on the sculpt                                                                                                                                                                                                                   |
| Quad Draw                     | Modeling Toolkit > Tools > Quad Draw; Mesh Tools > Quad Draw; Shift+right-click > Quad Draw Tool; Y re-activates the last tool | exit by clicking the tool again                                                                                                                                                                                                                        |
| Quad Draw options             | Ctrl+Shift+right-click in the tool; Tool Settings                                                                              | Auto-weld (on, 10 px on screen), Relax lock mode (Auto-Lock, Interior, Border, All), Extend mode (Edge, Loop, Border), Quad Strip Width (20 on screen), Live Constraint (Wireframe Overlay, Mesh Color, Mesh Alpha, Surface Offset, Snap to Backfaces) |
| Symmetry while drawing        | Modeling Toolkit > Symmetry (set before dropping dots)                                                                         | only on a 100% symmetric reference                                                                                                                                                                                                                     |
| Retopologize                  | Mesh > Retopologize > option box                                                                                               | Keep Original and Scan mesh for issues exist only here; progress in the Output window; hold Esc to cancel                                                                                                                                              |
| Edit the result               | Attribute Editor > polyRetopo tab; turn Pause on, change several attributes, turn it off                                       | then Edit > Delete by Type > History                                                                                                                                                                                                                   |
| Remesh                        | Mesh > Remesh                                                                                                                  | evens the spread before Retopologize                                                                                                                                                                                                                   |
| Flow Retopology               | Mesh > Flow Retopology (2027.1)                                                                                                | cloud, Autodesk sign-in, 50 jobs per month (2026)                                                                                                                                                                                                      |
| Cleanup (inspect)             | Mesh > Cleanup > option box: Select matching polygons, Nonmanifold geometry (plus lamina, zero-length edges, zero-area faces)  | inspect first; never let it triangulate n-gons (FlippedNormals clean-scene rule)                                                                                                                                                                       |
| Hard edges view               | Display > Polygons > Hard Edges (color)                                                                                        | scans often show every edge hard (purple)                                                                                                                                                                                                              |
| Soften, harden                | Mesh Display > Soften Edge / Harden Edge; Shift+right-click in object mode > Soften/Harden Edges                               |                                                                                                                                                                                                                                                        |
| Separate, merge               | Mesh > Separate; Mesh > Merge (tiny threshold)                                                                                 |                                                                                                                                                                                                                                                        |
| Mirror                        | Mesh > Mirror > option box: Merge threshold Custom 0.001, Border merge (antCGi)                                                | Shift+right-click > Mirror in FlippedNormals                                                                                                                                                                                                           |
| Recenter the middle line      | select the center vertices, Move tool, type 0 in world X                                                                       | FlippedNormals [00:19:06]                                                                                                                                                                                                                              |
| Edit Edge Flow                | Edit Mesh > Edit Edge Flow                                                                                                     | evens loops (FlippedNormals [00:27:53])                                                                                                                                                                                                                |
| Shrink wrap the low           | select low, then high, Deform > Shrink Wrap > option box                                                                       | On Mars [00:15:02]                                                                                                                                                                                                                                     |
| Transfer UVs or positions     | select source, then target, Mesh > Transfer Attributes (UV Sets All, Sample space World or Topology)                           | antCGi e74KphYwMww [00:20:05]                                                                                                                                                                                                                          |
| Smooth preview                | 1 off, 2 cage + smooth, 3 smooth                                                                                               | save with 1                                                                                                                                                                                                                                            |
| Rebuild a broken source       | Mesh > Booleans > option box: Geometry mode Volume, Voxel size (2026; default 1.000)                                           | needs a second input mesh; union, differences and intersection only                                                                                                                                                                                    |

Quad Draw hotkeys (2018 panel, [verify] in 2027)

| Hover outside the new mesh | Action                                         |
| -------------------------- | ---------------------------------------------- |
| LMB or MMB click           | drop a dot                                     |
| LMB drag                   | move a dot                                     |
| MMB drag                   | move dots along normals (no live surface only) |
| Ctrl+Shift+LMB             | delete dots                                    |
| Tab+LMB drag               | draw a quad strip                              |
| Tab+MMB drag               | resize the strip                               |
| Shift+LMB between dots     | create a face                                  |

| Hover inside the new mesh   | Action                                                                                    |
| --------------------------- | ----------------------------------------------------------------------------------------- |
| LMB drag                    | tweak components                                                                          |
| Ctrl+LMB on an edge         | insert an edge loop (dotted green preview)                                                |
| Ctrl+MMB                    | insert a centered loop                                                                    |
| Shift+LMB drag              | relax (Auto-Lock: border vs interior by where you start)                                  |
| Shift+MMB                   | relax the highlighted points                                                              |
| Tab+LMB drag a border edge  | extend the edge                                                                           |
| Tab+MMB                     | extend the border loop                                                                    |
| Ctrl+Shift+LMB              | delete faces, or an edge loop when clicking an edge                                       |
| Ctrl+Shift+MMB drag an edge | tweak an edge loop                                                                        |
| B, then Shift+MMB drag      | relax with Soft Selection (left drag undoes); Auto-weld is off while Soft Selection is on |

## UVs

| Task                       | Path                                                                                                                                         | Notes                                                                                                                                                                                                                                                                       |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| UV Editor                  | UV > UV Editor; Windows > Modeling Editors > UV Editor; UV Editing workspace                                                                 | the UV Toolkit is its side panel; Shift+click a toolkit button opens its options                                                                                                                                                                                            |
| Initial projection         | UV Toolkit > Create > Planar (or Cylindrical, Spherical, Automatic, Normal-Based, Camera-Based)                                              | MLC: Planar in Z for the whole body                                                                                                                                                                                                                                         |
| Cut seams in 3D            | UV > 3D Cut and Sew UV Tool: drag to cut, Shift-drag to stay on one loop, Shift+double-click a whole loop, Ctrl-drag to sew                  | cut in the viewport, not in 2D (MLC [00:01:06])                                                                                                                                                                                                                             |
| Auto Seams                 | UV Toolkit > Cut and Sew > Auto Seams (options: Seams Cut or select, Method default or hard edges, Shell Splitting Tolerance, Connect Holes) | refuses non-manifold meshes                                                                                                                                                                                                                                                 |
| Unfold                     | UV Toolkit > Unfold > Unfold; UV > Unfold > option box                                                                                       | Method Unfold3D; Iterations, Power 100, Prevent self border intersections, Prevent triangle flips, Map size, Room space 2 px                                                                                                                                                |
| Unfold Tool, Optimize Tool | UV Toolkit > Unfold > Unfold Tool / Optimize Tool                                                                                            | brush; Unfold Tool only with Unfold3D                                                                                                                                                                                                                                       |
| Optimize                   | UV Toolkit > Unfold > Optimize; Modify > Optimize > option box                                                                               | Surfangle 1, Power 100; Legacy (relax) is the old Relax                                                                                                                                                                                                                     |
| Straighten                 | UV Toolkit > Unfold > Straighten UVs (Shift+click for angle and axes); Straighten Shell                                                      | works better on smaller UV sets (MLC [00:05:53])                                                                                                                                                                                                                            |
| Align, pin                 | UV Toolkit > Align and Snap (align to max, min); Pinning > Pin / Unpin                                                                       | MLC straightening: align rows, pin, Optimize Tool on the interior                                                                                                                                                                                                           |
| Orient to Edges            | UV Toolkit > Arrange and Layout > Orient to Edges (select an edge along the desired V)                                                       | MLC [00:03:10]                                                                                                                                                                                                                                                              |
| Symmetrize                 | UV Toolkit > Transform > Tools > Symmetrize (click an edge on the line of symmetry; Ctrl+middle-drag moves the mirror axis)                  | cannot create UVs                                                                                                                                                                                                                                                           |
| Texel Density              | UV Toolkit > Transform > Texel Density: Map Size first, then Get on the reference shell, Set on the others                                   | 2027: Map Size is the base of the calculation                                                                                                                                                                                                                               |
| Measure                    | UV Toolkit > Arrange and Layout > Measure: U Distance, V Distance, Pixel Distance, Angle Between                                             | one shell at a time (Paulino)                                                                                                                                                                                                                                               |
| Layout                     | UV Toolkit > Arrange and Layout > Layout; Modify > Layout > option box                                                                       | Packing Resolution 256, Iterations 1, Multiple Objects, Pre-Rotation, Pre-Scale, Rotation Steps 90, Texture Map Size, Padding Units, Shell Padding, Tile Padding, Shell Distribution (Distribute with Tiles U, V, or Shell Centers), Scale Mode (Uniform, Non-Uniform, Off) |
| Stack, unstack             | Arrange and Layout > Stack Shells, Stack Similar, Snap & Stack, Unstack Shells                                                               |                                                                                                                                                                                                                                                                             |
| Select problems            | Select By Type > Overlapping, Unmapped                                                                                                       |                                                                                                                                                                                                                                                                             |
| Checker                    | UV Editor view bar checker icon; Textures > Checker Map                                                                                      | Viewport 2.0 needed                                                                                                                                                                                                                                                         |
| Distortion                 | UV Editor view bar distortion icon; View > UV Distortion                                                                                     | red stretched, blue compressed, white optimal, per shell; Viewport 2.0                                                                                                                                                                                                      |
