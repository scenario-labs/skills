# GUI paths for the same procedures (for a computer-use agent)

Menu paths from the Maya 2027 Help pages saved in the project and the notes; hotkeys only where a source states them. On macOS, Maya's docs map Ctrl to Control and Alt to Option, not Command. Not checked in a running Maya 2027: labels marked [verify] come from older pages or notes. The code path for each row is in `procedures.md`.

## Projects, files, references, namespaces

| Task                                      | Human path                                                                                                                  | Code                                                                                                                    |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Set the project                           | File > Set Project                                                                                                          | `cmds.workspace(root, openWorkspace=True)` [verify flag]                                                                |
| Reference a file                          | File > Create Reference (Ctrl+R per the pipeline note [verify]) ; option box: namespace = file name or custom string        | `P.reference(path, ns)`                                                                                                 |
| Load, unload, reload, replace, list edits | File > Reference Editor; right-click the reference node > Reference > List Edits                                            | `P.references_report()`, `P.reference_issues(...)` (R01 to R05), `P.swap_reference()`, `cmds.file(unloadReference=ref)` |
| Edit referenced animation curves          | Windows > Settings/Preferences > Preferences > File References: "Allow edits on referenced animation curves" (Ep.3 wording) | optionVar name not documented [verify]                                                                                  |
| Namespaces                                | Windows > General Editors > Namespace Editor                                                                                | `cmds.namespace`, `cmds.namespaceInfo`; mx_validate fix `namespaces`                                                    |
| Outliner with everything                  | Outliner > Display > uncheck DAG Objects Only (FlippedNormals troubleshooting move)                                         | `cmds.ls()` with types                                                                                                  |
| Plug-ins                                  | Windows > Settings/Preferences > Plug-in Manager (Loaded, Auto load, i for info)                                            | `mx_run --plugins`, `cmds.loadPlugin`, `cmds.pluginInfo`                                                                |
| Script Editor, echo                       | Windows > General Editors > Script Editor; History > Echo All Commands                                                      | `cmds.help("<command>")`                                                                                                |
