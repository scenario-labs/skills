# Critique rubric: judging pipeline work like a pipeline TD

Use after every stage and before any delivery. Each row: what the expert looks at, the measurable proxy (`mx_pipeline`, `mx_validate`, `mx_audit` or a snippet), the pass line, the severity. Severity: **block** = fix before anything leaves; **fix** = fix before delivery; **note** = report, accept if the brief allows. Calibrate: a run can pass with notes; do not turn a note into a block, and do not hide a block in a note. All proxies are not yet run in Maya.

## A. The batch run

| Look at                                                                            | Proxy                                                                                              | Pass                                                | Severity                            |
| ---------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | --------------------------------------------------- | ----------------------------------- |
| Every input accounted for                                                          | `summary["files"] == len(scenes)`; one `reports/<stem>.json` per scene                             | equal, no missing report                            | block                               |
| Sources never written                                                              | `summary["sources_untouched"]`, per-record `sha1_before == sha1_after`                             | True                                                | block                               |
| Crashes and hangs isolated                                                         | statuses `crash`, `timeout` limited to their own files; `attempts` recorded                        | the rest of the batch finished                      | block if one file stopped the batch |
| Failures explained                                                                 | every non-pass record has `error`, `issues` or `log_tail`                                          | a reason a human can act on                         | fix                                 |
| Tried on a sample first (Borderlands habit of testing the chain on the first pass) | a 5-file run before the full set, time per file recorded                                           | done, per-file seconds known                        | fix                                 |
| Fixtures prove the checks                                                          | one small scene per rule, expected issue ids reported (`test_engine_checks.py` pattern)            | every fixture caught                                | fix                                 |
| Resume is honest                                                                   | `resumed` only where sha1 and job signature match                                                  | changed files re-ran                                | fix                                 |
| Parallelism measured, not guessed                                                  | workers raised only after RAM and license behavior were observed [verify license use]              | stated in the report                                | note                                |
| Environment logged                                                                 | `maya` version per record, plug-in versions, mayapy path, `batch_env` (ADP off, logging levels)    | present                                             | note                                |
| Preflight before the batch                                                         | `P.preflight(out, scenes)`: mayapy, localhost and host name resolve at once, disk, readable scenes | ok, or the failing check fixed first (`/etc/hosts`) | fix                                 |
| Children not blind                                                                 | per-child FBX log name, stderr level `warning` (or `all` while debugging), `log_tail` on failures  | present                                             | fix                                 |

## B. Validation and safe fixes

| Look at                                                                                                                                              | Proxy                                                                                               | Pass                 | Severity                         |
| ---------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- | -------------------- | -------------------------------- |
| Read-only first                                                                                                                                      | validation before any fix; `before_summary` kept when fixing                                        | yes                  | block                            |
| Only safe fixes applied automatically                                                                                                                | fix log lists `history`, `smooth_preview`, `unknown_dead`, `namespaces` (or what the brief allowed) | nothing else         | block                            |
| Never auto-fixed: n-gons, non-manifold, lamina, facing, symmetry, units, frame rate, joint orientation, naming by side (FlippedNormals; mx_validate) | these appear only as issues                                                                         | yes                  | block                            |
| Weight changes bounded                                                                                                                               | `cap_influences` refused above `max_delta`; changed vertex count and max delta reported             | below 0.1 or refused | fix                              |
| Fixed version saved separately                                                                                                                       | `<out>/fixed/<stem>_fixed.ma` only when something changed                                           | yes                  | block if written over the source |
| Every fix logged with its nodes                                                                                                                      | `fixes[].done`                                                                                      | present              | fix                              |
| Re-validated after fixing                                                                                                                            | second validation summary                                                                           | no new failures      | fix                              |

| H17 edge smoothing deliberate      | mx_audit `hard_edges` count; eyes                                                                           | H34 new version, never over the published file | `save_version`, mx_run refusal, sha1 check                              |
