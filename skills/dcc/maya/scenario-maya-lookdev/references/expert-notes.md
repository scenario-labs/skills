## Arnold: OpenPBR Surface (official intro tEUiIBApw-U and the parameter doc)

- One physical stack: base substrate (metal or dielectric: glossy-diffuse, subsurface or translucent), optional coat with its own medium, optional fuzz, plus thin film, emission, thin-walled [00:01:12] [00:09:39] [00:10:51].
- Metals: base color = F0, specular color = F82 edge tint ("separately controls the color seen near the silhouette of the metals" [00:02:51]); chrome goes slightly blue at the edge; mirror = metalness 1, roughness 0, base color and weight 1 (Base Metalness). Twelve metals in `mx_shade.METALS_OPENPBR` (aluminum, brass, chromium, copper, gold, iron, nickel, platinum, silver, steel, titanium, zinc); some values exceed 1 (gold F0 red 1.059) and are used as printed. Base metalness between 0 and 1 is legitimate for rust [00:01:46].
- "It got darker" is physics: rough highlights are dimmer (energy conserved) [00:08:30]; a coat darkens the base (coat darkening default 1) [00:10:15]. Never fix by pushing weights above 1; only specular weight above 1 stays physical (Energy Conservation, Specular Weight).
- Transmission color is Beer-Lambert absorption, light and subtle; saturated values mean infinite density; with depth 0 the color is a non-physical tint. Depth is a world length: "if you see no effect, check scene scale" (Transmission Color, Depth).
- Dispersion: Abbe 10 to 70 typical, default 20, lower is more; off until dispersion scale is above 0 [00:07:41] [00:08:13]. The page prints "9 | 55 (diamond preset) | 92 (sapphire preset)" under an image row; real sapphire is about 72 [added].
- Subsurface: radius is mean free path ("the larger this radius, the more translucent" [00:05:20]); radius scale sets per-channel distance, not the rendered color; anisotropy toward 1 is forward scattering, more translucent with a brighter rim [00:05:53]; SSS needs outward normals, polymeshes only; `sss_setname` (now `interior_set`) blurs across shapes such as teeth and gums.
- Coat tints what is below; a rough coat roughens the base; coat normal separate from the base normal for rain, glazing, carbon fiber, car paint (Coat).
- Fuzz: weight = density, roughness = fiber shape; fabric, dust, peach fuzz (Fuzz).
- Thin film: micrometers, 0 to 1 useful, colors fade above 1 [00:12:35]; film IOR shifts the hue; drive thickness with a ranged noise (Thin Film).
- Emission: luminance in nits, 1000 nits matches Standard Surface emission 1 (What's New 2025, nits_per_unit); small bright emitters are noisy, use a mesh light when it must light the scene.
- Thin walled only for single-sided sheets; opacity below 1 only makes sense with thin walled or 0 everywhere (Geometry).
- Caustics off by default; on the outer cornea they add believability to eyes (Advanced).
- Arnold core defaults from `kick -info openpbr_surface` (What's New 2025, Arnold 7.3.4): base color 0.8, specular roughness 0.3, specular IOR 1.5, transmission depth 0, dispersion Abbe 20 and scale 0. The parameter tables print specular roughness 0.2 and coat roughness 0.1; the Maya node may differ again [verify with the probe].

## Arnold: Standard Surface, Standard Hair, subdivision and displacement (doc)

- Standard Surface semantics that differ: with metalness on, specular weight and color only control the edge tint; thin film in nanometers (0 to 2000, 3000 removes iridescence); SSS radius is the RGB color and scale the scalar; dispersion Abbe 0 = off; sheen instead of fuzz; coat affect color and roughness instead of darkening. Transmission scatter needs the mesh's Opaque on; opacity needs Opaque off. Randomwalk (default) handles concavities; v2 goes deeper in thin, backlit regions but is costlier and noisier. Coat color white for realistic cases; bare metal wants coat 0.
- Standard Hair: realistic hair has no diffuse and no tints; melanin 0.2 blonde, 0.5 red and brown, 1.0 black, melanin redness for pheomelanin, randomize for per-strand variation; textures go into base color with melanin 0; roughness 0.2; IOR 1.55 (outside 1.4 to 1.6 only for wet hair); shift 0 to 10 degrees (measured 2.3 to 3.7), 0 for synthetic; blond needs extra depth and more specular or AA samples; opacity below 1 costs a lot. MtoA 5.6 adds `scattering_mode`: accurate is rounder in close-ups but 10 to 30 percent slower, adaptive switches by on-screen thickness (What's New 2027). Load MtoA before XGen; XGen Interactive Groom assigns `hairPhysicalShader` by default (groom digest).
- Subdivision: iterations quadruple polygons per level (2 Maya smooth levels plus 4 Arnold iterations = 4096x); never stack Arnold subdivision on Smooth Mesh Preview, "Arnold will also render this preview smoothed state"; adaptive error 0 = uniform, stable in animation; raster space is a problem with instances.
- Displacement: map Raw, pre-processed with maketx; the displacement node on the shading group's displacement slot. Per-object height multiplies the shader's scale, per-object zero value adds to the shader's, padding takes the maximum, autobump on the shader wins. "The proper workflow ... is to have the shader give the final displacement value and then to offset the bounding box with the bounds padding attribute" (too low clips to black, too high is slow). Autobump moves high frequencies into bump, needs UVs, evaluates at Pref (bump2d on displaced points compounds). Vector displacement: catclark with enough iterations, 32-bit EXR, connect the whole vector, tangent space for deforming meshes.

## Color management for look dev (Maya 2027 help, Arnold ACES page, Brejon, Maya Learning Channel FODVxXOIrvM)

- OCIO v2 Maya-default config, ACEScg rendering space, ACES sRGB view (Maya 2027 help). The default input role is `sRGB Encoded Rec.709 (sRGB)` since 2026.2; the help spells linear sRGB "scene-linear Rec.709-sRGB" and "scene-linear Rec 709/sRGB"; ACES 1.x configs call Raw "Utility - Raw" (version deltas 2.7).
- Rules set the initial space of new file nodes only; Reapply Rules resets every node without Ignore Color Space File Rules; rules live in user preferences, so another machine or `mayapy` may assign other spaces (help; [added consequence]).
- EXR, HDR and float TIFF are almost always scene-linear Rec.709/sRGB; data maps Raw; plates in their camera space (help, Determine the correct color space). Under ACEScg, Raw means "no conversion", right only for data or files already in ACEScg (Brejon).
- Swatches and ramps are rendering-space numbers: changing the rendering space mid-project changes every color; delete .tx after a rendering-space change (help; Brejon Cornell box).
- Under the ACES sRGB view, scene 1.0 displays at about 0.81 and display white needs a bit more than 16 [FODVxXOIrvM 00:02:13]: pre-2022 values are re-judged, not copied.
