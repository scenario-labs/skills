## Toolkit decisions not taken from a source ([added])

Result files instead of socket replies for the bridge; the exchange directory `/tmp/mx_bridge_<uid>` at mode 0700; hard `os._exit` after `uninitialize`; Maya's stderr at `warning` in mayapy children; Maya messages captured by kind (warning, error, stack trace) with MCommandMessage and deduplicated against stderr; the deformer-input rule of `split_history` (a node whose every output ends on a deformer's non-geometry input); roots held by UUID across validation fixes; the checker default of 16 repeats per UV tile; silhouette computed from alpha so a license watermark never reaches it; duplicates in a temporary namespace for review renders; verdict thresholds `td_ratio_max=2.0`, `symmetry_min_pct=99.0`, zero tolerances relative to the bounding box diagonal (1e-6), overlap grid of 256 cells per UV unit. Each is documented where it is used and can be overridden.
