# Blender version deltas: what makes 2.8x to 4.x tutorials misleading in 5.2.1 LTS

Reference for condensing expert Blender tutorials (recorded on 2.80 to 4.2) into agent skills that drive **Blender 5.2.1 LTS** headless through `bpy`. Organized by domain. Each point reads "old tutorial says X -> in 5.2 do Y (bpy: ...)".

## Legend and provenance

- **[verified in 5.2.1]**: checked empirically on 2026-09-24 in `/opt/homebrew/bin/blender` = Blender 5.2.1 LTS (build 2026-08-25), Python 3.13.13, run as `blender --background --factory-startup --python ...`. Probe scripts: `archive/tests/version-deltas/probe1.py` to `probe9b.py`, `probe5_keymap.py`, `probe6_keymapdata.py`, `probe7_defaults.py`, `probe8_bake.py`.
- **[release notes]**: stated in the official release notes (link given), not re-tested.
- **[inferred]**: my reading of an API or UI detail, not confirmed. Treat with care.
- Release-note Markdown for 2.80 to 5.3 was pulled from the `blender-developer-docs` repo and cached in `archive/tests/version-deltas/rn/` for grepping. All links below point to the public pages `https://developer.blender.org/docs/release_notes/<version>/<page>/` (URL pattern checked, HTTP 200).
- Scripting gotcha found while verifying: `hasattr(bpy.types.Mesh, "color_attributes")` returns False for RNA _properties_ (it only sees functions). Test with `"prop" in bpy.types.X.bl_rna.properties` or on an instance. [verified in 5.2.1]
- Keymaps are **empty in `--background`** (`keyconfigs.default.keymaps[...].keymap_items` has 0 items). Shortcut facts below were read from the bundled keymap data (`scripts/presets/keyconfig/keymap_data/blender_default.py`) through `generate_keymaps()`. [verified in 5.2.1]

## 2. Headless scripting basics (read first)

- **Old:** `bpy.ops.object.delete({"selected_objects": objs})` -> **5.2:** `with bpy.context.temp_override(selected_objects=objs): bpy.ops.object.delete()`. Positional context dicts raise `ValueError: 1-2 args execution context is supported`. [verified in 5.2.1] ([4.0/python_api](https://developer.blender.org/docs/release_notes/4.0/python_api/)). 5.0 adds `override.logging_set(True)` to log which context members an operator reads ([5.0/python_api](https://developer.blender.org/docs/release_notes/5.0/python_api/)).
- Engine identifiers: `'BLENDER_EEVEE'`, `'CYCLES'`, `'BLENDER_WORKBENCH'`. Setting `'BLENDER_EEVEE_NEXT'` fails in 5.2.1. Note `RenderSettings.bl_rna.properties["engine"].enum_items` statically lists only `BLENDER_EEVEE`, so do not validate engines from that list. [verified in 5.2.1]
- Factory defaults: engine `BLENDER_EEVEE`, 1920x1080 at 24 fps, view transform `AgX`, look `None`, display `sRGB`, EEVEE `taa_render_samples=64`, `use_raytracing=False`; Cycles `samples=4096`, denoising on (`OPENIMAGEDENOISE`), light tree on, device `CPU`. [verified in 5.2.1]
- Python is 3.13 (5.1); the user site-packages directory is no longer loaded by default, pass `--python-use-user-env` to restore it. [verified 3.13.13 in 5.2.1] ([5.1/python_api](https://developer.blender.org/docs/release_notes/5.1/python_api/), [5.1/core](https://developer.blender.org/docs/release_notes/5.1/core/))
- `import bgl` fails (module removed in 5.0); `Image.bindcode` removed, use `gpu.texture.from_image()`. [verified in 5.2.1] ([5.0/python_api](https://developer.blender.org/docs/release_notes/5.0/python_api/))
- 5.2 adds `gpu.init()` to initialize the GPU backend in `--background`, `bpy.data.all_ids`, `Window.screenshot`, and expanded `bpy.data.file_path_foreach` options. [release notes] ([5.2/python_api](https://developer.blender.org/docs/release_notes/5.2/python_api/))
- `--background` disables audio by default (4.2). Log output format changed in 5.0: `--debug-cycles` -> `--log cycles`, `--debug-ffmpeg` -> `--log video`, `--verbose` -> `--log-level info|debug|trace`; render-farm log parsers need updating. [release notes] ([4.2/core](https://developer.blender.org/docs/release_notes/4.2/core/), [5.0/core](https://developer.blender.org/docs/release_notes/5.0/core/))
- `bpy.props`-defined properties are no longer reachable as dict items (`scene["cycles"]` no longer gives Cycles settings); use the RNA attributes. Blend-file compression is on by default. Data-block names can be 255 bytes. [release notes] ([5.0/python_api](https://developer.blender.org/docs/release_notes/5.0/python_api/), [5.0/core](https://developer.blender.org/docs/release_notes/5.0/core/))
- `mathutils` types now expose float32 buffers (numpy conversions change). Python subclasses of Blender types that define `__init__` must call `super().__init__(*args, **kwargs)` (4.4). IDProperties behind `bpy.props` and GN modifier inputs are statically typed (4.2). [release notes] ([5.0/python_api](https://developer.blender.org/docs/release_notes/5.0/python_api/), [4.4/python_api](https://developer.blender.org/docs/release_notes/4.4/python_api/), [4.2/python_api](https://developer.blender.org/docs/release_notes/4.2/python_api/))
- `bpy.ops.render.render()` accepts `frame_start`/`frame_end` (5.0). [release notes] ([5.0/python_api](https://developer.blender.org/docs/release_notes/5.0/python_api/))

## 3. Sculpting

### 3.1 Brush selection and the brush asset system (4.3)

- **Old:** pick brushes from the toolbar (one tool per brush), or `bpy.ops.paint.brush_select(...)` / `paint.brush_set` -> **5.2:** brushes are **assets** in the _Essentials_ library, picked from the asset shelf at the bottom of the viewport or the popup (`Shift+Space` with the default spacebar action "Play", plain `Space` if the keymap uses "Tools"). `paint.brush_set` does not exist. [verified in 5.2.1] ([4.3/sculpt](https://developer.blender.org/docs/release_notes/4.3/sculpt/))
- bpy (works headless once the object is in Sculpt Mode; 4.5 made it a blocking load in background):
  ```python
  bpy.ops.object.mode_set(mode='SCULPT')
  bpy.ops.brush.asset_activate(asset_library_type='ESSENTIALS', asset_library_identifier="",
      relative_asset_identifier="brushes/essentials_brushes-mesh_sculpt.blend/Brush/Clay Strips")
  b = bpy.context.scene.tool_settings.sculpt.brush   # 'Clay Strips', CLAY_STRIPS, size 70, strength 0.5
  ```
  [verified in 5.2.1] ([4.3/sculpt](https://developer.blender.org/docs/release_notes/4.3/sculpt/), [4.5/python_api](https://developer.blender.org/docs/release_notes/4.5/python_api/)). Assigning `tool_settings.sculpt.brush = ...` is not the way: `paint.brush` is read-only since 4.4 ([4.4/python_api](https://developer.blender.org/docs/release_notes/4.4/python_api/)).
- Essentials brush files live in `/Applications/Blender.app/Contents/Resources/5.2/datafiles/assets/brushes/`: `essentials_brushes-mesh_sculpt.blend` (64 brushes), `-mesh_texture` (15), `-mesh_vertex` (8), `-mesh_weight` (4), `-curve_sculpt` (11), `-gp_draw` (13), `-gp_sculpt` (9), `-gp_vertex` (5), `-gp_weight` (4). [verified in 5.2.1]
- Custom brushes: duplicate an essentials brush, then _Save As Asset_ (`bpy.ops.brush.asset_save_as`) into a user library; each brush is its own `.asset.blend`. Old files' local brushes need _Mark as Asset_ then _Save As Asset_. [verified op exists in 5.2.1] ([4.3/sculpt](https://developer.blender.org/docs/release_notes/4.3/sculpt/))
- Brush thumbnails, custom icons: `brush.use_custom_icon` / `icon_filepath` removed (5.0), use the asset preview. [verified absent in 5.2.1] ([5.0/python_api](https://developer.blender.org/docs/release_notes/5.0/python_api/))

### 3.3 Brush settings and API renames

- **Brush size is now a diameter** (5.0). A tutorial's "Radius 50 px" is `size = 100` in 5.x. RNA description of `Brush.size`: "Diameter of the brush in pixels". [verified in 5.2.1] ([5.0/sculpt](https://developer.blender.org/docs/release_notes/5.0/sculpt/))
- `brush.sculpt_tool` -> `brush.sculpt_brush_type`; likewise `image_brush_type`, `vertex_brush_type`, `weight_brush_type`, `gpencil_brush_type`, `curves_sculpt_brush_type` (5.0). [verified in 5.2.1] ([5.0/python_api](https://developer.blender.org/docs/release_notes/5.0/python_api/))
- `brush.curve` / `curve_preset` -> `curve_distance_falloff` / `curve_distance_falloff_preset` (5.0); pen-pressure curves for size/strength/jitter (5.0). [verified rename in 5.2.1] ([5.0/python_api](https://developer.blender.org/docs/release_notes/5.0/python_api/), [5.0/sculpt](https://developer.blender.org/docs/release_notes/5.0/sculpt/))
- `use_airbrush`, `use_anchor`, `use_space`, `use_line`, `use_curve`, `use_restore_mesh` -> one enum `brush.stroke_method` in `{'DOTS','DRAG_DOT','SPACE','AIRBRUSH','ANCHORED','LINE','CURVE'}` (5.1). [verified in 5.2.1] ([5.1/python_api](https://developer.blender.org/docs/release_notes/5.1/python_api/))
- Unified size/strength/color are per mode: `scene.tool_settings.unified_paint_settings` -> `scene.tool_settings.sculpt.unified_paint_settings` (5.0). [verified in 5.2.1] ([5.0/python_api](https://developer.blender.org/docs/release_notes/5.0/python_api/))
- Radial symmetry moved from tool settings to the mesh: `mesh.radial_symmetry` (5.0). XYZ mirror has been per mesh since 2.91: `mesh.use_mirror_x/y/z`. [verified in 5.2.1] ([5.0/python_api](https://developer.blender.org/docs/release_notes/5.0/python_api/), [2.91/sculpt](https://developer.blender.org/docs/release_notes/2.91/sculpt/))
- Automasking moved into a struct (5.2): `sculpt.use_automasking_topology` -> `tool_settings.sculpt.mesh_automasking_settings.use_automasking_topology` (same on `brush.mesh_automasking_settings`); `automasking_cavity_factor` -> `mesh_automasking_settings.cavity_factor`, etc. [verified in 5.2.1] ([5.2/python_api](https://developer.blender.org/docs/release_notes/5.2/python_api/))
- Brush and palette colors are stored in scene linear (5.0); sRGB hex values from tutorials need conversion or use the color picker's Perceptual sliders. [release notes] ([5.0/sculpt](https://developer.blender.org/docs/release_notes/5.0/sculpt/), [5.0/color_management](https://developer.blender.org/docs/release_notes/5.0/color_management/))
- Grab, Snake Hook, Elastic, Pose, Boundary, Thumb, Rotate no longer show pressure toggles (5.0). Tilt support for Draw, Draw Sharp, Plane, Clay Strips (4.5). [release notes] ([5.0/sculpt](https://developer.blender.org/docs/release_notes/5.0/sculpt/), [4.5/sculpt](https://developer.blender.org/docs/release_notes/4.5/sculpt/))
- Clay Strips was "overhauled" in 4.3, cloth brushes default _Persistent_ off (4.4): old strength values may not transfer. [release notes] ([4.3/sculpt](https://developer.blender.org/docs/release_notes/4.3/sculpt/), [4.4/sculpt](https://developer.blender.org/docs/release_notes/4.4/sculpt/))

### 3.4 Dyntopo, remesh, multires

- **Dyntopo.** Old: `Ctrl+D` toggles, "Smooth Shading" option in the Dyntopo panel -> 5.2: no default shortcut (removed 4.0), "Smooth Shading" removed (4.0), no confirmation dialog when enabling (5.2). bpy: `bpy.ops.sculpt.dynamic_topology_toggle()` works headless; `object.use_dynamic_topology_sculpting` reports state; defaults `detail_type_method='RELATIVE'`, `detail_size=12`, `detail_refine_method='SUBDIVIDE_COLLAPSE'`. `R` = detail size edit and `Ctrl+R` = detail flood fill when dyntopo is on. [verified in 5.2.1] ([4.0/keymap](https://developer.blender.org/docs/release_notes/4.0/keymap/), [4.0/sculpt](https://developer.blender.org/docs/release_notes/4.0/sculpt/), [5.2/sculpt](https://developer.blender.org/docs/release_notes/5.2/sculpt/))
- **Voxel remesh.** `mesh.remesh_voxel_size = 0.02; bpy.ops.object.voxel_remesh()` (Object or Sculpt Mode). Keys: `R` voxel size edit, `Ctrl+R` remesh. Voxel Size edit works in relative mode by default (4.3). Remesh propagates all attributes (4.1) and interpolates vertex/corner attributes such as colors instead of nearest sampling (5.2). [verified op and keys in 5.2.1] ([4.3/sculpt](https://developer.blender.org/docs/release_notes/4.3/sculpt/), [4.1/sculpt](https://developer.blender.org/docs/release_notes/4.1/sculpt/), [5.2/sculpt](https://developer.blender.org/docs/release_notes/5.2/sculpt/))
- **Quad remesh.** QuadriFlow is still built in: `bpy.ops.object.quadriflow_remesh(target_faces=500)` ran headless (523 faces). Its `Ctrl+Alt+R` shortcut was removed in 4.0. "Quad Remesher" in tutorials is the paid third-party add-on, not bundled. [verified in 5.2.1] ([4.0/keymap](https://developer.blender.org/docs/release_notes/4.0/keymap/))
- **Multires.** `object.multires_subdivide`, `multires_unsubdivide`, `multires_rebuild_subdiv` (2.90), `multires_base_apply` exist. In Sculpt Mode `Ctrl+0..5` runs `object.subdivision_set(level=N, ensure_modifier=True)` which adds a Multiresolution modifier; `Alt+1`/`Alt+2` step levels down/up (`Page Up/Down` now grow/shrink visibility). 5.0 added "Conform Base" beside "Apply Base": there is no separate operator in 5.2.1; `multires_base_apply` has a bool `apply_heuristic` (default True, "slightly alter base positions for a new subdivision modifier"), so Conform Base is presumably `apply_heuristic=False` [inferred]. [verified ops/keys in 5.2.1] ([2.90/sculpt](https://developer.blender.org/docs/release_notes/2.90/sculpt/), [4.0/keymap](https://developer.blender.org/docs/release_notes/4.0/keymap/), [5.0/sculpt](https://developer.blender.org/docs/release_notes/5.0/sculpt/))
- Bake from Multires supports n-gons, matches Subdivision Surface interpolation, and vector displacement (5.0). [release notes] ([5.0/rendering](https://developer.blender.org/docs/release_notes/5.0/rendering/))

### 3.5 Face sets, masks, hiding, trimming

- Face sets are opt-in since 3.4 (primitives start without them). Ops: `sculpt.face_sets_create`, `sculpt.face_set_edit`, `sculpt.face_set_change_visibility` (5.1 adds `active_face_set` param for scripts). Keys: `H` hide active face set, `Shift+H` toggle, `Alt+H` show all, `Ctrl+W`/`Ctrl+Alt+W` grow/shrink, `Shift+W` expand face set, `Alt+W` face set pie, `Page Up/Down` grow/shrink visibility. [verified keys/ops in 5.2.1] ([3.4/sculpt](https://developer.blender.org/docs/release_notes/3.4/sculpt/), [5.1/sculpt](https://developer.blender.org/docs/release_notes/5.1/sculpt/))
- Mask is a generic float attribute `.sculpt_mask` (4.1); `mesh.vertex_paint_mask` returns the attribute, `vertex_paint_mask_ensure()` creates it. ## 17. Grease Pencil v3 (rewrite in 4.3)

- **Types and data:** object type `'GPENCIL'` -> `'GREASEPENCIL'`; data type `bpy.types.GreasePencil` (it was `GreasePencilv3` in 4.3 to 4.5, renamed in 5.0); `bpy.data.grease_pencils` (was `grease_pencils_v3` in 4.3 to 4.5). Annotations are separate: `bpy.types.Annotation`, `bpy.data.annotations`, `AnnotationLayer` (renamed 5.0). [verified in 5.2.1] ([4.3/grease_pencil_migration](https://developer.blender.org/docs/release_notes/4.3/grease_pencil_migration/), [5.0/python_api](https://developer.blender.org/docs/release_notes/5.0/python_api/))
- **Modes and operators:** `EDIT_GPENCIL` -> `'EDIT'`, `PAINT_GPENCIL` -> `'PAINT_GREASE_PENCIL'`, `SCULPT_/WEIGHT_/VERTEX_GREASE_PENCIL`; `bpy.ops.gpencil.*` now holds only annotation ops, drawing ops are `bpy.ops.grease_pencil.*`; add with `bpy.ops.object.grease_pencil_add(type='STROKE'|'EMPTY'|'MONKEY'|'LINEART_SCENE'|...)` (old `object.gpencil_add` gone). `EDIT_GPENCIL` still appears in the `Object.mode` enum but GP objects enter `'EDIT'`. [verified in 5.2.1] ([4.3/grease_pencil_migration](https://developer.blender.org/docs/release_notes/4.3/grease_pencil_migration/))
- **Strokes are attributes on a drawing:**
  ```python
  gp = bpy.data.grease_pencils.new("GP"); ob = bpy.data.objects.new("GP", gp)
  layer = gp.layers.new("Lines"); frame = layer.frames.new(1)
  d = frame.drawing; d.add_strokes([4])            # was frame.strokes.new()
  for i, pt in enumerate(d.strokes[0].points):
      pt.position = (i, 0, 0); pt.radius = 0.05    # was point.co / point.pressure
  ```
  Attributes created: `curve_type`, `position`, `radius`; point props `position`, `radius`, `opacity` (old `strength`), `delta_time` (old `time`); `layer.info` -> `layer.name`, `layer.active_frame` -> `layer.current_frame()`. Stroke/point helper objects are not RNA types; do not cache them across edits. [snippet, attributes and point props verified in 5.2.1; renames release notes] ([4.3/grease_pencil_migration](https://developer.blender.org/docs/release_notes/4.3/grease_pencil_migration/))
- **Fills (5.1):** fill is a per-curve `fill_id` attribute (0 = not filled, so curves are **not filled by default**) plus `hide_stroke`; draw tool has Stroke/Fill/Both. GN `Set Material` with a GP material no longer fills. 5.2 exposes `stroke.fill_id`/`hide_stroke` in Python and makes the Delaunay fill solver the default. [release notes] ([5.1/grease_pencil](https://developer.blender.org/docs/release_notes/5.1/grease_pencil/), [5.2/grease_pencil](https://developer.blender.org/docs/release_notes/5.2/grease_pencil/))
- **Modifiers are regular modifiers:** `object.grease_pencil_modifiers` removed -> `object.modifiers.new(name, 'GREASE_PENCIL_THICKNESS')`; types `GP_*` -> `GREASE_PENCIL_*`, Line Art is `'LINEART'`. [verified in 5.2.1] ([4.3/grease_pencil_migration](https://developer.blender.org/docs/release_notes/4.3/grease_pencil_migration/))
- **Workflow changes:** strokes always world-space thickness (Screen Space option removed, use a GN setup); brush Radius Unit View/Scene; "Input Samples" -> Spacing; Simplify in pixels; eraser cuts strokes; Curve Edit mode replaced by stroke curve types; drawing guides and interpolate selection order not ported (4.3); Stroke Placement back (4.4); Fill Guides (4.5); corner types, Pen tool, motion blur (5.0); layer groups (4.3). Files saved in 4.3+ do not load correctly in 4.2. Brushes come from `essentials_brushes-gp_draw.blend` (Pencil, Pencil Soft, Pen, Ink Pen, Ink Pen Rough, Marker Bold, Marker Chisel, Airbrush, Tint, Fill, Eraser Hard/Soft/Stroke); 5.2 online textured brushes need Allow Online Access. [brush list verified; rest release notes] ([4.3/grease_pencil](https://developer.blender.org/docs/release_notes/4.3/grease_pencil/), [4.4/grease_pencil](https://developer.blender.org/docs/release_notes/4.4/grease_pencil/), [4.5/grease_pencil](https://developer.blender.org/docs/release_notes/4.5/grease_pencil/), [5.0/grease_pencil](https://developer.blender.org/docs/release_notes/5.0/grease_pencil/), [5.2/grease_pencil](https://developer.blender.org/docs/release_notes/5.2/grease_pencil/))

## 20. The 10 deltas that matter most for the skills

1. **Brush assets (4.3):** brushes are Essentials assets, activated with `bpy.ops.brush.asset_activate(... relative_asset_identifier="brushes/essentials_brushes-mesh_sculpt.blend/Brush/<Name>")`; many names changed (Crease Polish, Scrape/Fill, Pinch/Magnify, Elastic Grab, Density); Flatten/Fill/Scrape are one `PLANE` type. [verified]
2. **Brush size is a diameter (5.0)** and brush/automasking/unified settings moved (`sculpt_brush_type`, `stroke_method`, `mesh_automasking_settings`, per-mode unified settings, `mesh.radial_symmetry`). [verified]
3. **Auto Smooth is gone (4.1):** use `object.shade_auto_smooth` (Smooth by Angle modifier) or `shade_smooth_by_angle`; normals from `mesh.corner_normals`. [verified]
4. **Principled BSDF v2 (4.0):** renamed sockets, access by name; Emission Strength defaults to 0 with a white color. [verified]
5. **EEVEE Next (4.2):** Render Method replaces Blend Mode, bloom is a compositor Glare node, AO/SSR/soft-shadow toggles replaced by ray tracing and per-light jitter; engine id is `BLENDER_EEVEE` again in 5.x. [verified]
6. **Compositor as node group (5.0):** `scene.compositing_node_group`, Group Output instead of Composite, `ShaderNode*` math/mix/ramp nodes, options as inputs. [verified]
7. **Output `media_type` (5.0):** set `image_settings.media_type='VIDEO'` before any FFmpeg settings. [verified]
8. **Slotted Actions (4.4) + legacy Action API removed (5.0):** channelbags via `bpy_extras.anim_utils`; reassigned actions need `action_slot`; no multi-layer animation yet in 5.2.1. [verified]
9. **Bone collections (4.0) and pose-bone select/hide (5.0):** no layers or bone groups; `arm.collections`, `bone.color`, `pose.bones[n].select`. [verified]
10. **Grease Pencil v3 (4.3, renamed 5.0):** `GREASEPENCIL` objects, `bpy.ops.grease_pencil.*`, `frame.drawing` attributes, regular modifiers, `fill_id` fills (5.1). [verified]

Runners-up worth a line in every skill: AgX default and renamed color spaces (`Linear Rec.709`, `Non-Color`); I/K keying change; UV sync select on by default and explicit `method=` for unwrap; add-ons moved to Extensions (enable Node Wrangler/Rigify explicitly); GN modifier inputs through `md.properties.inputs` (5.2); keymaps unavailable in background mode.
