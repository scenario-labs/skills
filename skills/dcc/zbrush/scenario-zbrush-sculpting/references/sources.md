## Maxon documentation and SDK (2026)

- Brushes, strokes, alphas, auto masking, Lazy Mouse, Smooth, Layer brush (help.maxon.net, `sources/docs/fundamentals-sculpting__brushes-strokes-alphas.md`). Best for: Smooth only via Shift, Draw Size Dynamic mode, Layer constant depth, stroke types.
- DynaMesh, Sculptris Pro, subdivision levels, Geometry palette (`sources/docs/fundamentals-sculpting__dynamesh-sculptris-subdivision.md`). Best for: 1024 and 2048 cube limits, remesh conditions, Sculptris Pro restrictions, Divide needs no mask or hidden parts.
- Gizmo 3D, Transpose, deformers, Tool > Deformation (`sources/docs/fundamentals-sculpting__gizmo-transpose-deformers.md`). Best for: soft Gizmo unless Focal Shift -100, global axes of the Deformation sliders, deformers need no levels.
- Masking and polygroups (`sources/docs/fundamentals-sculpting__masking-polygroups.md`). Best for: masks modify all sculpting and Deformation actions, Mask Changed Points, Merge Stray Groups, QuickPolygroup.
- ZSpheres, layers, morph targets, SubTool palette (`sources/docs/fundamentals-sculpting__zspheres-layers-morph-extract-subtool.md`). Best for: Adaptive Skin, one Morph Target per SubTool, layer intensity, Groups Split keeps levels at the top level.
- Python SDK 2026.1 stubs and examples (`/Applications/Maxon ZBrush 2026/Documentation/python-api/`): `canvas_stroke` transforms from the stroke start in canvas space, `add_zsphere` only inside `edit_zsphere`, curves in tool coordinates (`zbrush.commands.add_curve_point.0.py`), `set_transform` example (0, 90, 90) = top view.
