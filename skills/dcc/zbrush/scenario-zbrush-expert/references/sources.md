## Maxon official (SDK and docs)

- ZBrush Python SDK 2026.1 manuals: quickstart, environment, libraries (Maxon SDK team), https://developers.maxon.net/docs/zbrush/py/2026_1_0/manuals/index.html, local copy `/Applications/Maxon ZBrush 2026/Documentation/python-api`. Best for: entry points (`-script`, startup plugins), interpreter limits.
- API overview, item paths, modifiers, camera transform (Maxon SDK team), https://developers.maxon.net/docs/zbrush/py/2026_1_0/manuals/api_overview.html. Best for: path rules (case and spaces ignored, picker items by name), what the API cannot see.
- GUI API reference (Maxon SDK team), https://developers.maxon.net/docs/zbrush/py/2026_1_0/api/zbr_cmds_gui.html. Best for: `set`/`press`/`get`, blocking calls, `canvas_click`, `update`, `freeze`.
- Modeling API reference (Maxon SDK team), https://developers.maxon.net/docs/zbrush/py/2026_1_0/api/zbr_cmds_modeling.html. Best for: `query_mesh3d`, strokes, `get_transform`, `pixol_pick`, SubTool status bits, ZSpheres, curves, maps.
- System API reference plus the stub (Maxon SDK team), https://developers.maxon.net/docs/zbrush/py/2026_1_0/api/zbr_cmds_system.html and `Documentation/python-api/api/zbrush/commands.py` (145 functions, dated 2025-10-28). Best for: `set_next_filename`, `zbrush_info`, the not-implemented `merge_undo` and broken `press_key`.
- Official examples (Ferdinand Hoppe, Javier Edo, Jan Wesbuer), https://developers.maxon.net/docs/zbrush/py/2026_1_0/examples/index.html and `examples/fragments/*.py`. Best for: hello world, SubTool array, batch export, turntable framing rule, the V03 stroke string, `pixol_pick` background 0x303030.
- Migrating ZScript and the command map (Maxon SDK team), https://developers.maxon.net/docs/zbrush/py/2026_1_0/manuals/migrating_zscript.html and `ZData/Python/zscript_command_mapping.json`. Best for: reading any ZScript macro as Python.
- Maxon developer forum, ZBrush SDK category (ferdinand, m_adam, i_mazlov, davide of the Maxon SDK team, and users), https://developers.maxon.net/forum/category/55/zbrush-sdk. Best for: current gaps (no SubTool rename, no mask data, FBX dialog, `press_key` failures, asset-directory `init.py`).
- ZScript command reference (Maxon help, originally Pixologic), https://help.maxon.net/zbr/en-us/Content/html/user-guide/customizing-zbrush/zscripting/command-reference/command-reference.html. Best for: argument orders, status bits, `FileNameSetNext`.
- ZScript interfaces, plugins, ZFileUtils, macros, user content (Maxon help), https://help.maxon.net/zbr/en-us/Content/html/user-guide/customizing-zbrush/zscripting/interfaces/zplugin-interface/zplugin-interface.html. Best for: one active ZScript at a time, macro folder rules, 2026.1 read-only install.
- ZScripting manual (Maxon help), https://help.maxon.net/zbr/en-us/Content/html/user-guide/customizing-zbrush/zscripting/technical/technical.html. Best for: learning paths from recordings, Ctrl+hover path display.
- Shipped 2026.2.1 macros, `/Applications/Maxon ZBrush 2026/ZData/Macros/` (Maxon, authors not named). Best for: known-good 2026 paths, `PopUp:<item>`, `IKeyPress` dialog answers, a recorded V02 stroke string.
- GoZ documentation (Maxon help), https://help.maxon.net/zbr/en-us/Content/html/user-guide/zbrush-other-programs/goz/goz.html, and GoZ SDK PDF, https://developers.maxon.net/docs/zbrush/goz_sdk.pdf. Best for: round-trip rules (lowest level, unique names), the `/Users/Shared/Pixologic` folder protocol.
- Maxon docs on canvas, ZTools, saving, SubTools, folders, LightBox, hotkeys and user content (`sources/docs/fundamentals-sculpting__basic-concepts-files-subtools.md`, `...__custom-ui-hotkeys-preferences.md`). Best for: file safety (.ZTL vs .ZPR vs .ZBR, QuickSave, versioning advice).
