# Prompt patterns

Templates for each generation step; the brackets are what you fill in. Field names come from each member's schema.

## Cast sheet (image model, the game sheet as reference)

> Cinematic 3D cast sheet for an animated feature-film trailer, translating the low-poly game characters in the
> reference into a photoreal stylized 3D animated feature film look. For each character: a close-up, front, side
> and back view, same colors, outfits and proportions. Neutral studio light, labels under each character.

## Still (image model, cast sheet and world frames as references)

> Cinematic film still from a photoreal stylized 3D animated feature film, characters exactly as in the reference
> cast sheet. [Location, time of day, weather.] [Shot size and angle]: [one action, described physically].
> [Light sources and color.] Anamorphic lens, shallow depth of field, 35mm film grain. 16:9.

## Motion (image to video, the still as first frame)

> Photoreal stylized 3D animated feature film. [What moves, in order, in real time.] [Camera move.] [Atmosphere:
> rain, dust, steam.] Real-time speed.

For a long move, give the first frame and the last frame and describe one continuous camera path between them.

## Narrator (text to speech)

> [deep, powerful epic movie-trailer voice, slow and dramatic] Thirty minutes... or less.

## Sound effect

> Quiet house at night with heavy rain on the windows, then slow, deep, earth-shaking giant footsteps approaching,
> BOOM... BOOM..., dishes rattling softly with each step.
